# Правила публичного распространения

[Русская документация](README.md) | [English source](../PUBLICATION_POLICY.md)

Опубликованный Toolkit **не должен содержать** имена частных проектов, идентификаторы приватных аккаунтов, индивидуальные лицензионные разрешения с подписями, учётные данные, внутренние пути, адреса развёртывания и документы только для сотрудников.

- **Clear Voice:** универсальная редакция материалов, предоставленных пользователем, с лицензией MIT и указанием сторонних авторов. Привязанные к исходному проекту профили заменены общими; оставлены только синтетические примеры.
- **QA Engineering Pack:** универсализированные рабочие методы, предоставленные пользователем. Перед публикацией проверяйте трудовые соглашения и правила обращения с внутренними данными работодателя.
- **Make Feature 0.3.0:** исходный автор - Artemiy Miller; компонент распространяется вместе с исходной лицензией MIT. Предоставленный архив также содержал персональную лицензию, явно запрещавшую дальнейшее распространение. Получатель сообщает, что правообладатель позднее отдельно разрешил любое использование, изменение и публикацию. Независимое подтверждение этого разрешения **не было предоставлено**. Из общедоступного пакета исключены персональные лицензионные файлы, имена, идентификаторы и адрес. Для публичного релиза сохраняйте письменное доказательство последующего разрешения **вне репозитория**.
- **Сторонние зависимости:** сохраняйте обязательные уведомления об авторских правах и происхождении. Установка пакета сама по себе не даёт права выполнять операции в проектах пользователей.

## Обязательная проверка прав перед будущим релизом (Issue #28)

Метки SPDX/MIT в исходниках описывают заявленные условия лицензирования, но **сами по себе не доказывают** право на распространение конкретного набора файлов. См. [аудит происхождения (EN)](../PROVENANCE_AUDIT.md) и `provenance/skills.json`.

Перед созданием **любого нового** тега или GitHub Release выполните `python scripts/validate_provenance.py --mode release` на дереве исходников предполагаемого релиза. Ошибка - **запрет на выпуск**, а не обычное предупреждение.

Сообщённое владельцем решение ID1337 отмечено как `permitted` для точных текущих байтов Make Feature 0.3.0, 41 опубликованного исходного объекта QA и двух фирменных изображений. Реестр фиксирует SHA256 **75 файлов** в этой области и их классификацию происхождения; изменённые, переклассифицированные или вновь добавленные файлы в согласованной области отклоняются.

**Это не означает независимой юридической проверки разрешения.** Для каждого нового публичного релиза по-прежнему требуется отдельное согласие владельца именно на его содержимое и условия. Решение ID1337 нельзя автоматически переносить на изменённые файлы без повторной проверки. Успешная проверка CI inventory не отменяет блокировку выпуска.

**Не загружайте в GitHub** личные разрешения, переписку и внутренние архивы работодателя. Сохраняйте существующие теги и получите отдельное явное решение владельца до исключения или замены Make Feature. Проверки GitHub уже опубликованного архива **не могут отменить** состоявшуюся публикацию.
