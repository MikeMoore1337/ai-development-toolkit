# У меня уже есть проект: с чего начать?

[English](../EXISTING_PROJECT.md) · [Начать без терминала](BEGINNER_START.md) · [Главная](../../README.ru.md)

**Если у вас есть готовый сайт, программа или репозиторий, устанавливать Toolkit не обязательно.** Это библиотека инструкций для ИИ, а не приложение с доступом к вашим файлам. Достаточно выбрать доступный способ передачи проекта и описать одну задачу.

## 1. Выберите, где ИИ увидит проект

| У вас есть | Как передать | Что проверить |
| --- | --- | --- |
| ChatGPT или Claude в браузере | В чате нажмите **«+» / скрепку / кнопку добавления файла** (название зависит от клиента) и приложите разрешённые файлы или небольшой ZIP. Если загрузка недоступна, вставьте нужные фрагменты текста | Попросите назвать файлы, которые ИИ действительно прочитал. Не предполагается доступ ко всему диску или запуск локальных тестов |
| Публичный репозиторий GitHub | Дайте **две ссылки**: на ваш проект и на [Toolkit](https://github.com/MikeMoore1337/ai-development-toolkit) | Клиент должен подтвердить, что может открыть обе ссылки. URL сам по себе не даёт доступа к закрытым файлам |
| Проект уже открыт в Codex / Claude Code | Укажите задачу в текущем проекте и ссылку на Toolkit | Проверьте, что агент видит правильную папку, а не только библиотеку инструкций. Изменения требуют разрешений |
| ChatGPT Work, если доступен | Используйте Work для более длительной работы с поддерживаемыми подключениями и разрешёнными файлами | **Work** — отдельный рабочий режим; обычный **Chat** — переписка и анализ переданных данных. Ни один режим не получает доступ к вашему компьютеру автоматически |

**Не присылайте пароли, токены, ключи, приватные файлы и данные клиентов.** Для начала достаточно `README`, одного-двух относящихся к проблеме файлов, текста ошибки или кратких шагов воспроизведения. Если материалов много, сначала спросите ИИ, что ему нужно.

## 2. Опишите задачу и границы

Скопируйте в выбранный клиент:

> Используй доступные файлы моего проекта и https://github.com/MikeMoore1337/ai-development-toolkit. Нужно: **[опишите проблему или цель]**. Сначала скажи, что тебе реально доступно и чего не хватает. Не удаляй данные, не публикуй проект, не трать деньги и не меняй файлы без отдельного разрешения. Предложи небольшой план, затем отчитайся о реально выполненных действиях и проверках.

Если это ошибка, добавьте: **что ожидалось → что произошло → как повторить → сообщение об ошибке**. Платный API, Git и терминал для отправки запроса не требуются.

## 3. Проверьте результат

| Статус | Что означает простыми словами |
| --- | --- |
| `PASS` | Проверка действительно выполнена и прошла, нужен её результат |
| `FAIL` | Проверка действительно выполнена и обнаружила ошибку |
| `NOT_RUN` | Проверку не запускали — нельзя утверждать, что всё работает |
| `NOT_VERIFIED` | Факт пока не подтверждён доказательством |
| `GUIDANCE_ONLY` | ИИ прочитал инструкцию, но это не означает применение навыка или исправление |
| `BLOCKED` | Действие остановлено из-за отсутствия доступа, инструмента или разрешения |

Слова `MCP` («подключение инструментов к ИИ») и `профиль` («набор инструкций под задачу») не нужно изучать для начала. `--apply` — технический параметр, который **подтверждает запись файлов после предварительного просмотра**; для обычного чата он не нужен.

**Главное:** файл навыка установлен ≠ ИИ обнаружил навык ≠ ИИ использовал навык ≠ приложение исправлено и проверено. Просите список изменений, реально исполненные тесты и честные `NOT_RUN`.

Для выбора клиента и его дополнительных возможностей см. [подробное сравнение](BEGINNER_CLIENT_DETAILS.md). [Технический контракт для ИИ-агента](../../AGENT_START.ru.md) адресован агенту, **не является первым шагом для человека**. Больше примеров — в [пути новичка](BEGINNER_START.md).
