# Предварительная проверка подключения Toolkit (read-only)

[English version](../PROJECT_ADOPTION_PREFLIGHT.md) | [Действующая процедура адаптации](../ADAPTATION.md)

Исходные правила проекта всегда главнее универсальных инструкций Toolkit: `AGENTS.md`, `CLAUDE.md`, архитектура, данные пользователей, визуальные согласования и порядок выпуска. Toolkit может **предложить** переносимые профили, но не имеет права самовольно менять файлы, присваивать пользовательские навыки, устанавливать сторонние пакеты или заявлять о фактическом использовании навыка ИИ-клиентом.

## Проверка перед установкой

В исходном каталоге Toolkit при установленном Python 3.12+:

```bash
python scripts/project_adoption_preflight.py --target /path/to/project --task qa --layout codex --archetype generic
python scripts/project_adoption_preflight.py --target /path/to/project --task ui --layout claude --archetype generic
```

На Windows/Linux/macOS используйте реальный локальный путь. `--archetype` задаётся **вручную** (для переносимого сценария используй `generic`; специфичные настройки репозитория требуют отдельной проверки): выводы о типе проекта не делаются из приватного кода. Команда переиспользует существующие `adt.choose` и `adt.diagnose`; проверяет только наличие заранее определённых имён файлов конфигурации и статус уже установленных навыков Skill Manager. Не читает содержимое `AGENTS.md`, `CLAUDE.md`, код приложения и личные заметки и не выполняет запись в проект.

## Интерпретация результата

- `READY_FOR_HUMAN_REVIEW` - очевидных локальных блокеров нет, но это **не** разрешение на установку, изменение, merge или deploy.
- `REVIEW_REQUIRED` - обнаружены пользовательские навыки либо необходимость ручной проверки; не перезаписывать файлы.
- `BLOCKED` - отсутствует проект, небезопасная ссылка, конфликт владения навыком, неподходящая среда или некорректное состояние менеджера.

Для L4 (обнаружение клиентом), L5 (реальное применение) и L6 (польза) всегда `NOT_TESTED`. Наличие `.agents/skills` или `.claude/skills` не подтверждает установку Codex/Claude Code. ChatGPT-плагин проверяется отдельно, по его реальному контракту.

После чтения **актуальных** правил проекта получить предпросмотр через существующий менеджер:

```bash
python scripts/adt.py profile plan --target /path/to/project --task qa --layout codex
```

Установка разрешается только отдельной явной командой `init --apply` после просмотра изменений, источников и владельцев файлов. У нового инструмента режима установки нет.

## Что проверить в любом проекте

| Область | Что проверить вручную |
| --- | --- |
| Пользовательский интерфейс | Визуальное согласование и ограничения на использование данных |
| Агентные сервисы | Доступ к секретам, инструментам и runtime; удалённый доступ не даёт права на публикацию |
| Приватные данные и внешние действия | Права доступа, подготовку, проверку и явное подтверждение до записи |
| Рабочие репозитории | Правила организации, существующие навыки и разрешения |

Тесты используют временные пустые, существующие, конфликтующие проекты и небезопасные ссылки. Они не являются реальными испытаниями действующих пользовательских проектов или рабочего ноутбука. Клиентская проверка отдельно учитывается в [#141](https://github.com/MikeMoore1337/ai-development-toolkit/issues/141).
