# Разработка и проверка ИИ-функций (Issue #57)

[English version](../AI_ENGINEERING_QA.md) | [Опциональный навык](../../extensions/ai/skills/ai-engineering-qa/SKILL.md)

LLM Evaluation - проверка наблюдаемого поведения ИИ-функции по независимым критериям, а не по одному удачному ответу. Версионированный контрольный набор с постоянными Case ID и SHA256 помогает воспроизводить ошибки. Регрессия промптов проверяет, сохранились ли обязательные поля, ограничения, корректная обработка ошибок и неопределённости. RAG - получение подтверждающих документов перед ответом: качество поиска (retrieval) и обоснованность отдельных утверждений (grounding) проверяются **по-разному**. Для tool-use отдельно проверяются параметры, права на запись, подтверждения и безопасные повторы.

## Начало без платных API

Запрос новичка: «Я сделал AI-помощника. Подготовь шесть проверок ответов, включая отсутствие фактов и выдуманные ссылки; укажи ожидаемые результаты и что можно проверить без модели».

Запрос специалиста: «Разработай версионированный контракт LLM/RAG/tool-use, эталоны релевантности, независимые проверки, регрессию промптов, негативные проверки прав и сравнение baseline/candidate».

Опциональный профиль: ai-engineering-qa. Сначала предварительный просмотр установки; не изменяйте чужой проект без согласия. В исходном репозитории Toolkit:

~~~sh
python scripts/validate_ai_contracts.py
python -m unittest tests.test_ai_contracts -v
python scripts/skill_routing_eval.py --strict
~~~

Полностью офлайн проверяются SHA набора, уникальность Case ID, обязательные поля и типы, фиксированные результаты ранжирования, принадлежность цитат найденным документам, границы вызовов инструментов и статусы доказательств. Все примеры вымышленные. Такие тесты **не измеряют** активацию реального AI-клиента, качество живой модели/поиска, содержательное обоснование утверждений, фактическую задержку или токены. Расход у провайдера без фактических данных - UNKNOWN. Блокировка платных испытаний Issue #11 сохраняется, второго исполнителя моделей нет.

Границы доказательств: PASS офлайн-эталона не подтверждает эффективность модели; действительный ID источника не подтверждает смысл утверждения; валидный tool contract не доказывает безопасное реальное выполнение. Реальная эффективность и активация - NOT_MEASURED.
