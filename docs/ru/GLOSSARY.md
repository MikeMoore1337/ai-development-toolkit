# Словарь терминов AI Development Toolkit

[Документация на русском](README.md) | [Первый запуск](GETTING_STARTED.md) | [English README](../../README.md)

| Термин | Значение |
| --- | --- |
| **Toolkit** | Набор повторно используемых инструкций и вспомогательных инструментов, а не самостоятельный ИИ-клиент |
| **Agent Skill / навык** | Каталог с `SKILL.md` и, возможно, дополнительными материалами. Он объясняет агенту, когда и как выполнять определённую задачу |
| **Профиль (`profile`)** | Подборка существующих навыков под цель (например, `qa-python` или `frontend`) |
| **ИИ-клиент** | Отдельно установленное приложение/среда, например Codex или Claude Code, которое может использовать навыки |
| **Предварительный просмотр (`preview`)** | Просмотр предполагаемых изменений без записи файлов; по умолчанию для изменяющих команд Skill Manager |
| **Применение (`--apply`)** | Явное разрешение менеджеру выполнить предварительно проверенную операцию с файлами |
| **Владение файлами (`ownership`)** | Учёт файлов, установленных самим Skill Manager; чужими файлами менеджер не управляет |
| **`status`** | Команда проверки состояния установленного менеджером набора |
| **`rollback`** | Предварительный просмотр и, после согласия, откат последней управляемой транзакции |
| **`AGENTS.md` / `CLAUDE.md`** | Локальные инструкции проекта, которые нельзя автоматически переписывать ради установки Toolkit |
| **`CI`** | Автоматические проверки кода и документации, например в GitHub Actions |
| **Регрессионная проверка** | Проверка, что изменения не сломали ранее работавшие сценарии |
| **Проверка структуры** | Проверка формата, ссылок, инвентаря и правил без запуска реального ИИ-клиента |
| **Реальная активация** | Подтверждённый факт, что конкретный клиент обнаружил навык и использовал его в работе. Не следует из успешной установки |
| **`main` и релиз** | `main` - актуальная ветка разработки; релиз - отдельно опубликованная версия с тегом |
| **Право на публикацию** | Отдельное решение владельца о выпуске конкретного артефакта; зелёный CI не заменяет его |

Имена команд, файлов, профилей и флагов оставлены в оригинале: их нельзя переводить при копировании примеров.

При спорных вопросах сверяйтесь с [английской документацией](../../README.md) и [правилами установки](../INSTALLATION.md).
