# Воспроизводимые архивы интеграций Toolkit

[English version](../PACKAGE_REPRODUCIBILITY.md) · [Обновление](UPDATING.md)

Используйте существующий сборщик двух **независимых пакетов интеграций**:

```bash
python integrations/build_packages.py --output /tmp/adt-bundles
```

В Windows PowerShell: `py -3 integrations/build_packages.py --output .\\adt-bundles`. Версия MCP читается как **литеральная константа** из `integrations/personal-mcp/adt-personal/mcp/adt_mcp.py` без запуска сервера. Версия ChatGPT-плагина читается из `integrations/chatgpt-plugin/ai-development-toolkit/plugin.json`. Обе версии не обязаны совпадать с `MANIFEST.json.version` (версия библиотеки навыков). Параметр `MANIFEST.json.chatgpt_personal_live.min_plugin_version` относится к отдельно установленному **персональному live-плагину**, а не к версии пакетного ChatGPT-плагина внутри этого репозитория.

ZIP-архивы формируются в отсортированном порядке с фиксированными метками времени и правами файлов, ограничениями размера и запретом symlink. Отчёт содержит SHA-256 каждого ZIP, SHA-256 инвентаря файлов исходника и количество записей. Повторная сборка при неизменных исходниках в **одном окружении** обязана дать совпадающие хеши. Разные версии zlib могут дать разные ZIP-байты, поэтому между компьютерами необходимо сверять зафиксированный проверенный хеш, а не считать бинарную идентичность гарантированной.

### Четыре разные границы

| Компонент | Меняет ли его сборщик? | Подтверждение |
| --- | --- | --- |
| Инструкции библиотеки в доверенном Toolkit SHA | Нет | Проверенный Git SHA / MANIFEST, отдельный механизм обновления |
| Локальный MCP пакет | Создаёт **только ZIP-кандидат** | Версия исходного сервера, SHA-256 ZIP, офлайновые тесты |
| ChatGPT пакет | Создаёт **только ZIP-кандидат** | plugin.json.version, SHA-256 ZIP, офлайновые тесты |
| Уже установленный MCP/плагин в клиенте | **Никогда** | `NOT_VERIFIED` до живого испытания |

Статус `SOURCE_ARCHIVES_BUILT_NOT_INSTALLED` означает: архивы подготовлены, но **не опубликованы и не установлены**. Установка новой оболочки требует отдельного одобренного действия и повторного подключения клиента либо импорта через ChatGPT. Для восстановления сохраняйте известные корректные архивы и проверенные ревизии исходников. Нельзя считать текущий `main` эквивалентом опубликованного релиза без проверки SHA и CI.

### Отрицательные случаи

Офлайновые тесты проверяют отсутствие версии, динамическую подстановку вместо буквальной версии, опасные пути, symlink, слишком большие файлы, изменение хешей и воспроизводимость. Эти проверки не доказывают работу установленного Codex/Claude/ChatGPT, наличие публикации, пользовательские права или сетевую доступность. Платные API и сторонние исполняемые загрузки не используются.
