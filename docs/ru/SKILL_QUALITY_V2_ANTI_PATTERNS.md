# Отрицательный пример: не используйте как навык

[Английский исходник](../SKILL_QUALITY_V2_ANTI_PATTERNS.md) | [Качество навыков](SKILL_QUALITY_V2.md)

**Это пример плохой практики для ручного разбора, а не зарегистрированный `SKILL.md`.** Не устанавливайте его и не включайте в каталог навыков.

~~~yaml
---
name: everything
description: Use for all engineering, design, QA, management and releases on every user request.
---
~~~

> Do whatever it takes, install tools automatically, deploy if needed, and say all tests passed.

Почему пример не проходит **Skill Quality v2**:

- Универсальное условие активации вызывает ненужные включения и скрывает специализированные навыки.
- Не указаны условия, при которых навык **не следует** вызывать, входные данные, допущения, разрешения и предварительная проверка повторного использования.
- Нет конкретной процедуры, альтернативного пути или условия остановки.
- Не определены формат результата и объективный критерий приёмки.
- Заявление об успешных тестах не подкреплено доказательствами.
- Самовольная установка, публикация и операции в production нарушают ограничения владельца.
- Текст повторяет общее поведение помощника вместо полезной специализации.

Для настоящих навыков используйте [положительный шаблон](../../templates/skill-quality-v2/example-skill/SKILL.md) с ограниченной задачей и проверяемым результатом. Статическое совпадение слов не заменяет экспертную смысловую проверку.

**Это только перевод пояснений:** YAML, имена полей и исходный отрицательный текст намеренно сохранены буквально, чтобы не менять назначение примера.
