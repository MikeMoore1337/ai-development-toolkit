# Отрицательный пример: не используйте это как навык

[English source](../SKILL_QUALITY_V2_ANTI_PATTERNS.md) | [Стандарт качества v2](SKILL_QUALITY_V2.md)

Это **учебный антипаттерн для ручного разбора**, намеренно не зарегистрированный как `SKILL.md`.

~~~yaml
---
name: everything
description: Use for all engineering, design, QA, management and releases on every user request.
---
~~~

> Do whatever it takes, install tools automatically, deploy if needed, and say all tests passed.

Почему пример не проходит Skill Quality v2:

- Универсальное условие запуска вызывает ненужную активацию и скрывает специализированные навыки.
- Нет отрицательных условий запуска, входных данных, допущений, полномочий и проверки возможности повторного использования.
- Нет конкретной процедуры, альтернатив или условий остановки.
- Нет требований к выходному результату и проверяемого критерия приёмки.
- Заявление об успешных тестах не подкреплено доказательствами.
- Установка инструментов, публикация и действия в production без разрешения нарушают ограничения владельца.
- Повторяется общее поведение ИИ-помощника вместо выполнения ограниченной задачи.

Используйте [положительный шаблон навыка](../../templates/skill-quality-v2/example-skill/SKILL.md) с ограниченной задачей и проверяемым результатом. Статическое совпадение слов не заменяет ручную смысловую экспертизу.

Английские поля `name` и `description`, а также намеренно плохой пример выше сохранены **без исправления**: это предмет теста, а не рекомендуемая инструкция.
