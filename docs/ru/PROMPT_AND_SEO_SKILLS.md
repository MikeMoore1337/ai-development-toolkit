# Навыки улучшения промптов и SEO

[English](../PROMPT_AND_SEO_SKILLS.md)

Два независимых переносимых навыка без обязательных платных API:

| Запрос | Профиль | Результат |
| --- | --- | --- |
| «Сделай нормальный промпт из сумбурного текста» | `prompt-refinement` | Один пригодный к использованию промпт без выполнения задачи |
| «Проведи SEO-аудит сайта» | `seo-audit` | Проверяемые находки, приоритеты и способы проверки |

Локальная установка - существующий маршрут **Preview -> Apply -> Status**. Плагин ChatGPT и MCP выбирают профиль по намерению; изменение GitHub не означает автоматическое обновление установленного плагина. Актуальные инструкции разрешено объявлять загруженными только после проверки SHA/CI и фактического чтения исходников.
