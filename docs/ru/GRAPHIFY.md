# Оригинальный Graphify для локального анализа кода

Graphify - **необязательный внешний инструмент разработки**, а не
зависимость Toolkit, его установщика, Personal MCP или профилей QA.
Используется [оригинальный Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)
без форка. Официальный пакет - `graphifyy`, лицензия Apache-2.0.
Основная ветка исходного репозитория - `v8`. Для проверки выбран релиз
[`v0.9.97`](https://github.com/Graphify-Labs/graphify/releases/tag/v0.9.97)
от 27.10.2026. Перед сменой версии нужно повторно проверить релиз и уязвимости.

## Изолированная установка (только по согласию пользователя)

Установите `uv` или `pipx` штатным способом для своей ОС. Не добавляйте
Graphify в окружение приложения:

```sh
uv tool install 'graphifyy==0.9.97'
graphify --version
```

Альтернатива - `pipx install 'graphifyy==0.9.97'`.
Первое скачивание требует сети и разрешения на установку программы.
Сам Toolkit **не запускает установку автоматически**. Минимум upstream -
Python 3.10; совместимость именно с Windows/Python 3.14 и Codex Desktop
требует настоящего запуска на целевой машине.

## Нативные команды без собственной реализации

Из корневого каталога **конкретного** репозитория:

```sh
graphify extract . --code-only --no-cluster
graphify explain "adt.py"
graphify path "adt.py" "skill_manager.py"
graphify query "what code depends on scripts/adt.py?"
```

`--code-only` строит локальный AST-граф без модели, API-ключа или
семантической отправки исходников. `--no-cluster` сохраняет исходные
извлечённые связи. Граф не заменяет актуальный исходный код и тесты.

**Корень Toolkit содержит штатный [`.graphifyignore`](../../.graphifyignore)**
с 69 проверенными правилами из [#423](https://github.com/MikeMoore1337/ai-development-toolkit/issues/423):
`third_party`/vendor, зависимости, кэши/build, `.env*`, credentials,
приватные пути и четыре локальных JSON-отчёта. Оригинальный Graphify 0.9.97
автоматически читает его вместе с `.gitignore` **при первом запуске нового
checkout**, без дополнительной обёртки и параметров `--exclude`.

Если при прошлом построении были заданы `--exclude`, оригинальный CLI
**сохраняет их в производной конфигурации текущего графа** и использует
при последующих запусках. Это не заменяет `.graphifyignore` для нового
checkout. При изменении правил полного AST-индекса можно выполнить
`graphify extract . --code-only --no-cluster --force`.

Для исключения внешней ссылки на vendor намеренно не индексируется
`scripts/native_eval_capsules.js`. При анализе влияния изменений в этом
модуле читайте исходники и тесты напрямую. У части узлов пустой
`source_file`; нулевые совпадения по маскам не доказывают отсутствие
любых секретов.

Запускайте только из корня **нужного** репозитория, не из домашней папки
и не из каталога над несколькими проектами. Не передавайте
`--no-gitignore`. `graphify-out/` - временные данные, исключённые
из Git; проверяйте их на приватность и не публикуйте. Эти правила
`.graphifyignore` относятся к **Toolkit**, а не автоматически ко
всем пользовательским проектам. `query` может вернуть нерелевантные
или усечённые по бюджету результаты. Проверяйте вывод `EXTRACTED`/
`INFERRED` по исходному коду и тестам.

## Codex Desktop - только добровольное подключение

После согласия владельца целевого проекта и проверки ожидаемых изменений
можно использовать **штатный upstream skill**:

```sh
graphify install --platform codex --project
```

Если оригинальный Graphify skill уже доступен в текущей сессии
Codex Desktop через пользовательскую установку, **используйте его**
без создания второй копии. Необязательная проектная установка выше
копирует оригинальный skill в `.codex/skills/graphify/` и штатные
`references/`. До изменений проверьте `git diff`, `AGENTS.md`,
существующие навыки, хуки и разрешения; не перезаписывайте чужие файлы.

Не запускайте отдельный `graphify codex install`: этот режим может
изменять `AGENTS.md` и Codex hooks и здесь не разрешён. В Codex
вызывают `$graphify`, а не `/graphify`. Codex CLI не нужен. Инструкция
сама по себе не доказывает обнаружение навыка или успешное выполнение.

Уже существующий навык Toolkit `graphify-adapter` остаётся
необязательным универсальным адаптером и сам ничего не устанавливает.

Не включайте автоматически strict hooks, перехват чтения исходников,
`watch`, Graphify MCP, Cloud, платные API/LLM, индексирование соседних
репозиториев и фоновое обслуживание. Приоритет имеют текущая Issue,
правила и реальный код проекта. При недоступности Graphify продолжайте
обычным поиском по исходникам.

## Обновление и откат

```sh
uv tool upgrade graphifyy                 # после проверки нового релиза
uv tool install --reinstall 'graphifyy==0.9.97'
uv tool uninstall graphifyy
```

Для `pipx` используйте аналогичные команды. Перед удалением штатно
установленного проектного skill проверьте diff, чтобы не удалить чужие
файлы. Graphify не требует изменений production, CI и runtime Toolkit.

**Статус доказательств (29.10.2026):** [#423](https://github.com/MikeMoore1337/ai-development-toolkit/issues/423)
содержит реальную Windows/Codex Desktop приёмку оригинального Graphify:
обнаружение навыка, code-only граф, CLI и ограниченную проверку путей
и связей. Штатный `.graphifyignore` оформлен отдельно в
[#474](https://github.com/MikeMoore1337/ai-development-toolkit/issues/474).
Эти проверки относятся только к фактическому окружению и области:
нет доказательств универсальной совместимости, абсолютного отсутствия
секретов или экономии токенов. Платные API и фоновая установка не включены.
