# Выборочный откат через Git - безопасная альтернатива Claude Code Rewind

Задача [Toolkit #372](https://github.com/MikeMoore1337/ai-development-toolkit/issues/372). Реализована **локальная Git-ориентированная** функция без установки агента, hook, API, фонового наблюдения и копирования чатов. Она работает с **коммитами**, а не с каждым действием Claude Code: это не полная реализация Rewind и не его форк.

## Почему оригинал не установлен

Проверен `holasoymalva/claude-code-rewind@d421d069384ab3349d7e798d72b3794628559b86`.

- README заявляет MIT и автоматические snapshots, но файл `LICENSE` в корне upstream отсутствует; в `pyproject.toml` лишь текстовый признак `MIT`. Полный лицензионный текст для переиспользования не подтверждён.
- Каталог `claude_rewind/hooks/` содержит только `__init__.py`; утверждение о полностью работающей автоматической регистрации hook не подтверждается проверенной структурой исходников.
- В `claude_rewind/core/rollback_engine.py` выполняются операции над `self.project_root / file_path` из снимка без видимой обязательной проверки разрешённого корня непосредственно перед записью/удалением. Нужны отдельные adversarial tests на traversal/symlink, прежде чем разрешать оригиналу менять рабочие проекты.
- README приводит неподтверждённые заявления об ускорении; они не используются в выборе решения.

**Решение:** оригинальную интеграцию не активировать; вместо неё использовать существующий Git с ограниченной оболочкой. Не создавать параллельную систему snapshots или скрытую службу.

## Применение

Из корня Toolkit на собственном тестовом клоне, Python 3.12+ и Git:

```sh
python scripts/safe_git_rewind.py --repo /path/to/project timeline --count 10
python scripts/safe_git_rewind.py --repo /path/to/project preview --commit <full-40-char-sha> --file src/example.py
```

`preview` показывает diff, текущий `HEAD`, SHA файловых объектов и **ничего не меняет**. Если файл из старого коммита действительно нужен, выполнить отдельное сознательное действие с точным HEAD из preview:

```sh
python scripts/safe_git_rewind.py --repo /path/to/project apply --commit <full-40-char-sha> --file src/example.py --expect-head <current-head-sha> --confirm
```

`apply` касается **только одного** существующего отслеживаемого обычного файла за вызов, меняет только worktree, а не индекс/ветку/коммиты. Откажется от неполного SHA, смены HEAD, незакоммиченных или staged изменений этого файла, неизвестного файла, symlink/junction, путей за корнем и `.git`. Исходное содержимое сохранено в Git на прежнем HEAD; для отмены сделанного восстановления используйте обычную проверенную процедуру `git restore --source=HEAD --worktree -- src/example.py`, предварительно проверив изменения.

Ограничения: Git-коммиты не являются историей всех действий агента; untracked/удалённые/конфликтные файлы не восстанавливаются; нет автоматического разрешения конфликтов и нет защиты от конкурентной записи иного процесса **между** последней проверкой и `git restore`. Выполнять только в изолированном checkout, не на живом production. Установки стороннего Claude Code Rewind, изменения пользовательских файлов и реальной проверки в личном Codex/Claude клиенте **не было**.

Проверки: `python -m unittest discover -s tests -p test_safe_git_rewind.py -v` - без сети, AI или API. Приёмка оригинального upstream: `NO_GO`; безопасный Git-адаптер: `SOURCE_ONLY` до успешного PR/post-merge CI.
