# Подробное сравнение ИИ-клиентов

Этот справочник содержит подробности, официальные ссылки и ограничения. **Для старта читать его необязательно.** Доступность функций зависит от конкретного аккаунта и разрешений.

## Выберите ИИ-клиент

| Клиент и режим | Самый простой путь | Может изменить приложение? | Может запустить тесты? | Навыки Toolkit | Терминал |
| --- | --- | --- | --- | --- | --- |
| [OpenAI Codex](#openai-codex), облачная среда | Выбрать подготовленный GitHub-проект в Codex Cloud | Да, в доступной облачной копии; локальный режим Desktop может работать с выбранной папкой | Да, при наличии инструментов, зависимостей и разрешений | Для Codex документирован каталог `.agents/skills`, но его нужно реально добавить в нужный проект | **Не нужен** для работы через настроенный облачный интерфейс; локальная установка через менеджер Toolkit требует CLI |
| [ChatGPT](#chatgpt), Chat / Work | Открыть чат или доступный Work, приложить материалы | Chat готовит тексты и файлы; Work может изменять доступные ему источники при наличии подключений и разрешений | Только в режиме с реальными инструментами исполнения, не гарантируется в обычном чате | Skills рабочего пространства и плагины **не равны** локальным `SKILL.md` Toolkit; автоматическое подключение не подтверждено | **Не нужен** для обсуждения и загрузки файлов |
| [Claude Code](#claude-code), Desktop Code / облако | Открыть вкладку Code и выбрать существующий проект или доступную облачную среду | Да, внутри разрешённого проекта/сеанса | Да, если доступны инструменты исполнения и зависимости | Поддерживается `.claude/skills`; установка менеджером Toolkit - отдельная операция CLI | **Не нужен** для уже настроенной Desktop-сессии, но установка и зависимости могут требовать команд |
| [Claude](#claude), чат / Projects | Начать диалог или Project и загрузить нужные материалы | Готовит текст и артефакты; не получает автоматически доступ к локальному проекту | В доступном режиме с включённым исполнением кода, не тесты локального репозитория по умолчанию | Пользовательские навыки можно загрузить **ZIP-архивом через Customize > Skills** при наличии функции | **Не нужен** для чата или поддерживаемой загрузки ZIP; подготовка ZIP может потребовать отдельного шага |

Это **проверенные по документации возможности на 20.10.2026**, а не результат запуска четырёх клиентов. Доступность зависит от тарифа, региона, платформы, настроек организации и разрешений. Если кнопка отсутствует, не считайте это ошибкой пользователя. Для чтения этого руководства платные API не нужны; доступ к отдельным возможностям клиента нужно уточнять по своему аккаунту.

### OpenAI Codex

**Подходит:** если нужно действительно менять код в GitHub-репозитории или локальном проекте.

1. Откройте [Codex Cloud](https://learn.chatgpt.com/docs/cloud) в браузере или Desktop. При необходимости подключите разрешённый GitHub-репозиторий. Новую облачную среду можно подготовить и опубликовать **после проверки её настроек и полномочий**. Если среда уже готова, используйте её. На телефоне можно выбрать существующую среду; первоначальная настройка описана для браузера и Desktop.
2. Выберите среду и вставьте один [готовый запрос](BEGINNER_START.md#пять-готовых-запросов). Сразу запретите публикацию, платные действия и развёртывание без согласования. Перед коммитом или PR изучите изменения и результаты тестов.
3. **Чтобы применить навыки Toolkit**, соответствующие каталоги должны действительно находиться в нужном репозитории по пути `.agents/skills/<имя-навыка>/SKILL.md`. Чтение README Toolkit не подключает навыки к чужому проекту. Используйте [существующий CLI](BEGINNER_START.md#необязательная-локальная-установка) в подходящей среде или попросите уполномоченного coding-агента подготовить изменения для проверки.
4. Нет доступа к репозиторию или подготовленной среде? Получите описание минимальной версии приложения и список файлов, а не фиктивный отчёт об изменениях.

**Терминал:** необязателен для подготовленного облачного интерфейса; для самостоятельного запуска локального менеджера `adt.py` он нужен. Codex Desktop может работать с выбранными локальными папками, но требует установленного приложения и доступа к файловой системе. Доступность и лимиты уточняются в аккаунте OpenAI; бесплатность выполнения не гарантируется.

**Официальные источники (проверено 20.10.2026):** [Codex Cloud](https://learn.chatgpt.com/docs/cloud), [каталоги навыков Codex](https://learn.chatgpt.com/docs/build-skills), [различия ChatGPT и Codex](https://help.openai.com/en/articles/20001275). **Не проверено:** обнаружение, фактическое применение и полезность навыков в работающей сессии.

### ChatGPT

**Подходит:** для обсуждения идеи, анализа доступных документов, планирования приложения и проверки кода теми средствами, которые реально включены в выбранном режиме.

1. Откройте [ChatGPT](https://chatgpt.com/). Используйте обычный Chat или доступный вам Work. При необходимости создайте Project для связанных бесед и файлов; загружайте только разрешённые материалы.
2. Вставьте [готовый запрос](BEGINNER_START.md#пять-готовых-запросов). Попросите перечислить **фактически доступные инструменты**. Обычный чат может подготовить код или файл, но это не означает изменение либо тестирование вашего репозитория.
3. Если доступен Work и вы предоставили ему доступ к репозиторию, подключённому приложению или локальной папке через Desktop, можно отдельно разрешить конкретные изменения. Work в браузере и на телефоне **не получает автоматически доступ к файлам на компьютере**. Проверяйте подтверждение записи и результаты тестов.
4. **Навыки Toolkit:** переданные в чат инструкции могут служить контекстом, но наличие локального навыка для Codex или загруженного README не доказывает его обнаружение ChatGPT. Skills рабочего пространства и плагины имеют **свои механизмы установки и разрешений**.

**Альтернатива:** если Work, запись файлов или доступ к репозиторию недоступны, получите спецификацию или готовые файлы для последующего применения, а тесты отметьте `NOT_RUN`. Для этого терминал не нужен.

**Официальные источники (проверено 20.10.2026):** [работа с ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt), [ChatGPT Work и Codex](https://help.openai.com/en/articles/20001275), [раздельные механизмы Skills](https://learn.chatgpt.com/docs/enterprise/skills), [доступ ChatGPT к GitHub](https://help.openai.com/en/articles/11145903-connecting-github-to-chatgpt-drease). **Не подтверждено:** автоматическое подключение локальных Toolkit skills в обычном чате.

### Claude Code

**Подходит:** для работы с существующим кодом через ИИ-агента, которому разрешён доступ к проекту.

1. Откройте [Claude Desktop Code](https://code.claude.com/docs/en/desktop), выберите вкладку Code и локальную папку/сеанс либо доступную облачную среду. Проверьте запросы доверия к проекту и разрешения. Для локального интерфейса нужно установленное Desktop-приложение, но запуск из терминала - не единственный способ.
2. Опишите одну задачу, запросите изучение проекта и небольшой план до изменений, затем проверьте разницу файлов и фактический вывод тестов. Локальная настройка проекта и зависимости могут требовать выполнения команд, даже если человек пользуется только интерфейсом.
3. Текущий менеджер Toolkit с `--layout claude` устанавливает навыки в `.claude/skills/<имя-навыка>/SKILL.md`. Клиент документирует такой каталог, но копирование подтверждает только состояние файлов, а не реальное использование. Синхронизируемые навыки аккаунта claude.ai - другой механизм; облачная сессия не наследует произвольные локальные каталоги.
4. Нет Desktop, прав на установку, проекта или средств исполнения? Подготовьте предложение изменений или перейдите в доступную разрешённую среду разработки.

**Официальные источники (проверено 20.10.2026):** [Desktop для Claude Code](https://code.claude.com/docs/en/desktop), [навыки и область видимости](https://code.claude.com/docs/en/skills). **Не проверено:** обнаружение и использование навыков Toolkit в живом Claude Code.

### Claude

**Подходит:** для идей, анализа загруженных файлов, описаний функций и подготовки артефактов.

1. Откройте [Claude](https://claude.ai/), начните диалог или Project и добавьте краткое описание либо разрешённые файлы. Projects помогают хранить контекст, но не дают автоматически доступ к локальному репозиторию.
2. Вставьте [готовый запрос](BEGINNER_START.md#пять-готовых-запросов). Попросите указать, что **не менялось** и **не выполнялось**.
3. **Дополнительный путь Skills через интерфейс:** если доступно `Customize > Skills` и включены исполнение кода/создание файлов, Anthropic документирует загрузку **ZIP с каталогом навыка и SKILL.md**. Сначала проверьте исходники и содержимое архива. Это **не установка менеджером Toolkit** и не гарантия поддержки для любого аккаунта. Загружайте только минимальный разрешённый навык, не весь Toolkit, не защищённые или личные файлы; учитывайте ограничения организации.
4. Если загрузка навыков недоступна, вставьте небольшой несекретный фрагмент руководства в чат. Для реальных изменений в репозитории при отсутствии инструмента записи понадобится другая разрешённая среда разработки.

**Официальные источники (проверено 20.10.2026):** [Claude Projects](https://support.claude.com/en/articles/9517075-what-are-projects), [пользовательские навыки Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude), [структура ZIP навыка](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills). **Не проверено:** успешная загрузка, обнаружение или использование конкретного архива навыка Toolkit.
