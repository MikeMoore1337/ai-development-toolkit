# Приоритет оригинальных сторонних инструментов (#492)

[English](../EXTERNAL_NATIVE_BOUNDARY.md)

Если пользователь **явно выбрал оригинальный сторонний инструмент, плагин, MCP, навык или агента**, Toolkit сохраняет предусмотренные разработчиком команды, режимы, агенты, hooks и рабочий процесс. Собственные контроллеры, навыки, роли, этапы и ограничения поведения Toolkit не подмешиваются автоматически. Простое упоминание или сравнение продукта не означает его выбора. Принцип действует и для будущих подключений. Работа над UX/UI Orchestra ведётся отдельно.

Обязательные правила платформы и хоста, разрешения пользователя и проекта, защита секретов, согласие на расходы и правила merge/deploy сохраняются. Это приоритет **поведения**, а не расширение полномочий.

## Честные типы интеграций

| Тип | Значение |
| --- | --- |
| `NATIVE_UPSTREAM` | Реально установленный и вызванный оригинал с подтверждённой версией |
| `TOOLKIT_ADAPTER` | Обёртка или частичное подключение с явным описанием недоступных функций |
| `HARDENED_FORK` | Оригинал с документированным исправлением безопасности и различиями |
| `REFERENCE_ONLY` | Источники или методика прочитаны, оригинальный runtime не вызван |
| `TOOLKIT_NATIVE` | Самостоятельная реализация Toolkit, не оригинальный продукт |

Ponytail в режиме skill-only не заменяет полный плагин с hooks; запускатор Harness² без моделей не заменяет оригинальный CLI; Graphify отличается от QA-адаптера Toolkit; Task Observer / Curator в ChatGPT - адаптации, не оригинальные Claude-агенты.

## Передача управления

Когда выбран внешний контроллер, клиент **не должен** вызывать маршрутизацию Toolkit. При случайном вызове в `toolkit_route_task`, `toolkit_prepare_task` или `toolkit_prepare_stage` передаётся точный наблюдаемый идентификатор `external_controller`. Ответ `NATIVE_UPSTREAM_PASSTHROUGH` не загружает навыков и ролей, ничего не устанавливает и не запускает. Он не доказывает настоящий запуск оригинала. Без параметра работает прежняя маршрутизация Toolkit. Автоматическое распознавание активного внешнего контроллера не заявляется.

Отдельный запрос на справку Toolkit допускает только адресное чтение `toolkit_get_skill` / `toolkit_get_reference`, но не смену контроллера. Если оригинал недоступен, нельзя выдавать адаптацию за него.

## Hooks и приёмка

Стандартное событие Codex `Stop` не содержит идентификатора стороннего контроллера или активного процесса Toolkit. Префикс `<!-- ADT-MODEL-ADVISOR-ACTIVE -->` может быть сформирован моделью или сторонним инструментом и **не подтверждает** владение задачей. Stop hook теперь требует отдельно подтверждённое доверенным клиентом `adt_workflow_scope=TOOLKIT_MODEL_ADVISOR` и не вмешивается при наличии `adt_external_controller`. Обычный Codex Stop-event такого поля не содержит, поэтому hook безопасно возвращает `{}`. Синтетический положительный тест не подтверждает поддержку клиентом. Ранее установленные hooks и инструкции нужно обновлять в клиенте отдельно.

Проверки: `python -m unittest discover -s integrations/personal-mcp/adt-personal/tests -v`, `python scripts/validate_pack.py`, `python scripts/verify_checksums.py`. Кодовые проверки не подтверждают нативную активацию в Codex Desktop/ChatGPT; нужна физическая проверка. Личные ограничения владельца на CLI и стоимость не являются универсальными для всех пользователей.
