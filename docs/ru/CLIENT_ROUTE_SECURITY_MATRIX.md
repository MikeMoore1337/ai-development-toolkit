# Маршруты клиентов: безопасность, возможности и доказательства

[English](../CLIENT_ROUTE_SECURITY_MATRIX.md) | [Задача #389](https://github.com/MikeMoore1337/ai-development-toolkit/issues/389)

**Область проверки:** исходники и контракты Toolkit, а не установленное ПО или подписка конкретного пользователя. Toolkit предоставляет универсальные инструкции, навыки и необязательные локальные MCP-инструменты. Оплата, учётная запись, секреты и реальные возможности принадлежат выбранному клиенту. Нельзя подменять проверку работающего подключения чтением документации.

## Подключение и подтверждённый уровень поддержки

| Маршрут | Где начать | Что проверено | Стоимость и ограничение |
| --- | --- | --- | --- |
| Обычный ChatGPT | [Без терминала](BEGINNER_START.md), ссылка/файлы Toolkit | Подсказки; доступ в конкретном сеансе NOT_VERIFIED | Toolkit не делает платных API-вызовов. Лимиты определяются планом и клиентом. |
| Плагин ChatGPT | [Инструкция по плагину](../../integrations/chatgpt-plugin/README.ru.md) | Контракт ZIP/исходников; установка и использование в конкретном клиенте требуют проверки | Импорт не является обращением к API Toolkit; условия аккаунта зависят от хоста. |
| Codex Desktop | [Локальный Personal MCP](../../integrations/personal-mcp/README.ru.md), общие инструкции | Проверены структура и контракты MCP; отдельные наблюдения не доказывают работу у всех | Лимиты и подписка определяются клиентом. Настройки не запускают Codex CLI. |
| Codex CLI | [Проектный MCP](../MCP_INSTALL.md) или [Skill Manager](../CLIENT_MIGRATION.md) | Проверены офлайн-контракты и работа с файлами; реальный запуск NOT_VERIFIED | Пользователь проверяет свой план/API-счёт и квоты; Toolkit не вызывает CLI автоматически. |
| Claude Code CLI | [Проектный MCP](../MCP_INSTALL.md) или [Skill Manager](../CLIENT_MIGRATION.md) | Офлайн-контракты и файловые операции; реальный запуск NOT_VERIFIED | Подписка/API-оплата и исполнение принадлежат клиенту. Бесплатность не гарантирована. |
| Claude.ai в браузере | [Совместимость клиентов](../CLIENT_CAPABILITIES.md) | Контракт обычного чата; L4/L5 не доказаны для произвольного сеанса | Тариф и ограничения хоста проверяются отдельно. |
| MCP | [Обзор интеграций](../INTEGRATIONS.md) | Исходники сервера и конфигурации; подключение клиента отдельно | Запуск read-only MCP не даёт прав на запись, сеть, модели или оплату. |
| Прямой API | [Предпросмотр политики](../CLIENT_POLICY_ROUTES.md) | **Только рекомендации по маршруту** | Реальный API-исполнитель не реализован в этой функции. Настройка не создаёт ключ или предел расходов. |
| Другие чаты / Harness | [DeepSeek Chat](../../integrations/deepseek-chat/README.ru.md), [Harness](../../integrations/deepseek-harness/README.md) | Статические инструкции/контракты; активация NOT_TESTED | Нельзя считать подтверждёнными доступность моделей, оплату или использование навыков. |

**Статус универсальности:** одинаковая доступность всех программ и вызовов для всех пользователей не доказана. Если фактического запуска нет, указывается `NOT_VERIFIED`, а не `PASS`.

## Общие требования безопасности

| Вопрос | Что делает Toolkit и что должен проверить пользователь |
| --- | --- |
| Вход и секреты | JSON-настройки отклоняют неожиданные поля. Ключи API, пароли и токены не размещаются в публичном Git, `.adt/config.json` и отчётах. Авторизация производится через личный механизм выбранного клиента. |
| Расходы и квоты | По умолчанию `allow_paid_api=false`, `allow_cli_agents=false`, `additional_spend_allowed=false`. Разрешение рассмотреть маршрут - **не лимит расходов**. Перед реальным запуском отдельно проверяются тарифы, баланс, квоты и технический предел расходов, если он поддерживается провайдером. |
| Файлы | Предпросмотр ничего не записывает. Для Skill Manager применяется отдельное подтверждённое `--apply`. Агенту требуется разрешение в рамках задачи, доверенный каталог и соблюдение `AGENTS.md` и правил проекта. |
| Сеть | Предпросмотр не обращается к API. Параметр `allow_network` только описывает предпочтение; сетевые права и адреса определяет среда запуска. |
| Изоляция | Для экспериментов нужны временный проект или отдельно подтверждённая изолированная среда. Секреты хоста, SSH и инструменты не становятся безопасными из-за наличия тестов исходников. |
| Подтверждение / отмена | `ask` требует согласия, бесконтрольного `allow` нет. Предпросмотр всегда выдаёт `execution_authorized=false`. Реальное действие отменяется средствами клиента или провайдера. |
| Windows / Linux / macOS | Предпросмотр на Python 3.12+ работает на стандартной библиотеке, CI проверяет три ОС. Совместимость конкретного клиента и установленных версий определяется отдельно. |
| Доказательства | Успех проверки исходников L1-L3 не подтверждает обнаружение навыка L4, его использование L5 и пользу L6. Для повышения статуса нужны данные настоящего сеанса. |

## Что пока намеренно не разрешено

Настройки объединяются по уровням **универсальные < пользователь < проект < задача**; более узкий уровень может ужесточить ограничения, но не ослабить их. Для проверки: `python scripts/toolkit_preferences.py --target PATH`, затем `python scripts/client_policy_route.py --client codex-desktop`.

В `scripts/agent_eval_runner.py` остаётся `OWNER_REAL_AGENT_EXECUTION_LOCKED = True`. Настройки `allow_cli_agents` и `allow_paid_api` **не отключают этот запрет**. Реальный запуск, подтверждения, управление бюджетом и поддержка провайдеров требуют отдельной реализации. Никаких Codex/Claude CLI или платных API эти примеры не вызывают.

**Отключение:** удаляйте локальный файл настроек только после проверки, что он больше не используется; управляемые навыки удаляйте через механизм Skill Manager, а MCP или плагин отключайте в интерфейсе своего клиента. Удаление JSON не удаляет ПО и не отзывает ключи провайдера.
