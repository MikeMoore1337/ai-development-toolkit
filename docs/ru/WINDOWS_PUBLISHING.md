# Устранение проблем с публикацией в Windows

[English source](../WINDOWS_PUBLISHING.md) | [Настройка GitHub](GITHUB_SETUP.md) | [Правила распространения](PUBLICATION_POLICY.md) | [Процесс выпуска](RELEASE_PROCESS.md)

Это руководство относится **только к первой публикации другого, нового репозитория**, а не к обновлению или релизу официального AI Development Toolkit. Не запускайте `scripts/publish_github.ps1` для уже существующего официального репозитория. Обычное сопровождение ведётся через проверенные PR, защищённую `main`, согласование прав и описанный порядок выпуска.

При первой публикации скрипт автоматически выбирает `py -3`, если в Windows установлен Python Launcher, иначе использует `python`.

## Разрешение запуска сценария PowerShell

Если Windows блокирует неподписанный файл, **сначала изучите его содержимое**, затем при необходимости снимите отметку о загрузке *только с этого файла*:

```powershell
Unblock-File -LiteralPath .\scripts\publish_github.ps1
```

## Зависимости и предварительные проверки (только первая публикация)

```powershell
py -3 -m pip install -r requirements-dev.txt
py -3 scripts/check_public_package.py
py -3 scripts/validate_pack.py
py -3 -m unittest discover -s tests -v
.\scripts\publish_github.ps1
```

**Этот пример не является командой обновления Toolkit.** Первоначальный скрипт создаёт публичный GitHub-репозиторий после отдельного явного подтверждения. Повторная публикация существующего Toolkit этим способом не разрешена.

## Символьные ссылки и точки соединения каталогов

В Windows операция `Path.symlink_to` иногда завершается `WinError 1314`, если не включён Developer Mode и нет нужной привилегии. Если создание обычной символьной ссылки запрещено, проверка переносимости использует NTFS directory junction. Установщик отвергает **оба способа перенаправления** при выборе пути установки.

GitHub Actions для Windows запускает эти тесты с Python 3.14. Нельзя ослаблять проверку путей или пропускать тесты безопасности ради успешного выпуска.

**Успешный CI, работа PowerShell и наличие ZIP не доказывают публикацию GitHub Release, отсутствие расходов либо наличие прав на распространение.**
