# Визуальные аннотации для UI-задач (совместимо с Agentation)

**Назначение:** переносимый протокол ручной передачи замечаний для разных пользовательских проектов. Toolkit - библиотека навыков и QA, а не React-приложение. Документ **не** устанавливает, не копирует и не запускает [Agentation](https://github.com/benjitaylor/agentation), не подключает MCP, не добавляет контроллер или разрешение на изменения интерфейса.

Agentation `3.1.2` распространяется под **PolyForm Shield 1.0.0**, **не MIT**. Перед добровольной установкой в конкретный проект проверить ограничения на конкурирующие продукты и сохранение лицензии. Если условия не подходят, используйте другие инструменты скриншотов/разметки. В Toolkit исходники Agentation не включены.

## Локальное использование

Если потребительский проект использует React 18+ и desktop-браузер, разработчик может самостоятельно включить Agentation **только в dev-сервере** (например, opt-in в Vite `serve`). Исключить импорт из production entry point и собранных ассетов. Не устанавливать пакет автоматически из Toolkit, не подключать CDN, MCP endpoint или webhook по умолчанию. Мобильный браузер официально не поддерживается - проверять мобильные состояния отдельно в Playwright или на устройстве.

## Контракт замечания

Скопированный вручную текст от владельца - **указание на элемент**, а не доказанный дефект. Сохранять пакет в задаче/чате **целевого проекта**, не в Toolkit:

| Поле | Что записать |
| --- | --- |
| `issue`, `baseline_sha` | Задача и точный SHA или `UNKNOWN` |
| `route`, `state` | Маршрут и состояние (загрузка, ошибка, пусто, действие); удалить приватные query-токены |
| `viewport`, `theme`, `locale` | Размер, тема, язык и при необходимости платформа |
| `source`, `privacy` | `SYNTHETIC` / `DEMO` / разрешённый `LIVE` и результат проверки приватности |
| `selector` / `sourceFile` | Подсказка, которую нужно проверить по актуальному DOM/коду |
| `note`, `expected` | Что наблюдает пользователь и как должно работать |
| `evidence_refs` | Реальные скриншоты/наблюдения либо `NOT_OBSERVED` |
| `owner_gate` | `NOT_REQUESTED`, `PENDING`, `OWNER_ACCEPTED` с доказательством |

Для нескольких замечаний использовать короткие ID `F1`, `E1`; сверять selector и DOM с текущей версией. Не выдавать копирование текста за самостоятельную проверку браузера и не выдумывать отсутствующие скриншоты.

### Пример (синтетика, не подтверждённый дефект)

```text
F1 | issue: DEMO-1 | baseline_sha: UNKNOWN
route: /example | state: empty | viewport: 390x844 | theme: dark | locale: ru
source: SYNTHETIC | privacy: REVIEWED_NO_PRIVATE_DATA
selector: [data-testid="example-action"] (непроверенная подсказка)
note: На синтетическом состоянии кнопка выглядит обрезанной.
expected: Видимый текст и доступный фокус с клавиатуры.
evidence_refs: NOT_OBSERVED
owner_gate: PENDING
```

## Приватность и согласование

Agentation может включить в копию видимые и соседние тексты, селекторы, атрибуты, URL, CSS и расположение исходных файлов. **До отправки ИИ, в GitHub или внешнюю систему** вручную убрать секреты, токены, session ID, личные записи, приватные адреса и пути, пользовательские данные. Использовать синтетические/демо-состояния. Нельзя записывать протоколы, снимки, отчёты, историю чужих задач и персональные данные в репозиторий Toolkit.

Приоритет у `AGENTS.md` целевого проекта, его токенов UI, процесса визуального согласования и релиза. Аннотация не разрешает редизайн, правку DOM, публикацию, merge, deploy, сетевую отправку или включение агента. Существенные изменения интерфейса идут через существующую `ux-ui-design-orchestra`; принятая точечная правка всё равно требует настоящих до/после и проверки поведения.

## Статусы

- `LOCAL_ANNOTATION_COPIED`: пользователь передал текст; браузер не подтверждён.
- `SOURCE_ONLY`: изучен исходный код, отрисовка не проверена.
- `RENDERED`: фактическая проверка интерфейса с route/state/viewport.
- `NOT_OBSERVED`: визуального свидетельства нет.
- `VISUAL_PACKAGE_MISSING`: нельзя считать дизайн готовым к согласованию.
- `NOT_EXECUTED`: внешний инструмент не устанавливался и не запускался.

PASS синтетических тестов не означает, что Agentation реально открылся в desktop-браузере. Такой факт необходимо подтвердить отдельно.
