# Интеграции AI Development Toolkit - возможности и среды применения

AI Development Toolkit предоставляет **две равноправные интеграции** с общей библиотекой навыков, ролей и процессов: [плагин ChatGPT](../../integrations/chatgpt-plugin/README.ru.md) и [локальный MCP для Codex](../../integrations/personal-mcp/README.ru.md). **Способ подключения зависит от среды работы и доступности проекта**, а не от приоритета одних пользователей над другими. Платный API не требуется.

## Возможности Toolkit

- **Подбор навыков и ролей под задачу.** Обе интеграции выбирают узкий набор подходящих инструкций, а не весь каталог. Рекомендация навыка не доказывает его фактическое применение.
- **Подключение недостающих инструкций по необходимости.** Плагин ChatGPT использует встроенные материалы или доступную проверенную ревизию GitHub. Codex запрашивает инструкции через `toolkit_prepare_task`, передавая сведения об уже доступных навыках. Роль - это инструкции, **не** автоматически запущенный субагент.
- **Работа без копирования файлов в проект.** Обе интеграции могут предоставлять инструкции без изменения рабочего репозитория. Установка нативных навыков через Skill Manager - отдельное действие по явному разрешению.
- **Актуальные источники.** Плагин при наличии доступа может читать инструкции из согласованной проверенной ревизии GitHub во время задачи; иначе сообщает об использовании встроенного набора. Локальный MCP читает собственную копию Toolkit, которую можно обновлять по расписанию. **Код установленного плагина и MCP обновляется отдельно.**
- **Соблюдение границ доступа.** Проект доступен лишь через полномочия соответствующего клиента. Инструкции Toolkit сами по себе не дают доступа к файлам, репозиториям и терминалу.

## Выбор интеграции по рабочей среде

| Возможность | ChatGPT-плагин | Локальный MCP для Codex |
| --- | --- | --- |
| Где используется | В ChatGPT, когда доступны пользовательские плагины | На компьютере с Codex CLI и Python |
| Windows | Интерфейс ChatGPT | PowerShell; планировщик Windows |
| Linux | Интерфейс ChatGPT | Shell; пользовательский systemd |
| macOS | Интерфейс ChatGPT | Shell; launchd |
| Мобильные устройства | Если клиент ChatGPT поддерживает плагин | Локальная установка Codex не предусмотрена |
| Доступ к рабочему проекту | Переданные файлы, разрешённые подключения и источники | Рабочая область, доступная Codex, **не** MCP напрямую |
| Подбор навыков | Маршрутизатор плагина | `toolkit_route_task` / `toolkit_prepare_task` |
| Обновление инструкций | Чтение GitHub при подтверждённой доступности; иначе встроенный набор | Обновление локальной копии по расписанию, если включено |
| Обновление самой интеграции | Отдельный выпуск плагина | Отдельный выпуск MCP |
| Установка навыков и изменение файлов проекта без разрешения | Нет | Нет |
| Необходимость платного API | Нет | Нет |

## Установка и использование

**ChatGPT:** [Инструкция RU](../../integrations/chatgpt-plugin/README.ru.md) · [English](../../integrations/chatgpt-plugin/README.md)

**Codex MCP (Windows, Linux, macOS):** [Инструкция RU](../../integrations/personal-mcp/README.ru.md) · [English](../../integrations/personal-mcp/README.md)

**Другие чат-клиенты:** ZIP ChatGPT не является универсальным форматом для Claude, DeepSeek и Qwen. При отсутствии совместимого плагина используйте [AGENT_START.ru.md](../../AGENT_START.ru.md), ссылку на Toolkit и разрешённые файлы проекта. Не заявляйте об установке и применении навыка без фактического подтверждения.

**Границы доступа:** плагин навыков ChatGPT не получает автоматический доступ к локальному MCP на ноутбуке. Не публикуйте личные идентификаторы плагинов, токены или корпоративные файлы. Размещение исходников в GitHub само по себе не устанавливает интеграции пользователям.
