## Изменения

- **Нативная безопасность #432:** существующие `external_skill_gate.py` и `cisco_mcp_gate.py` расширены проверками небезопасных hooks PowerShell/Python, MCP-команд, широких прав Read, symlink/junction, доступных всем на запись каталогов POSIX, повторных JSON-ключей, точного типа версии схемы и ограниченных вариантов prompt injection. Обновлены SARIF 2.1.0 и SHA-256. Новый сканер, обязательный ECC/AgentShield runtime и платные API не добавлены.
- **Независимый синтетический корпус:** 60 случаев зафиксированы до настройки правил. На ранее закрытой выборке из 20 случаев TP=8 FP=4 TN=6 FN=2: precision 66,67%, recall 80%, F1 72,73%, FPR 40%, FNR 20%. После её раскрытия она использовалась только для регрессии. Это **не** точность защиты от реальных атак.
- **Cursor:** ранее слитый нативный плагин, безопасное подключение, переиспользование Personal MCP и постепенная маршрутизация навыков (#545, #546, #548). Наличие файлов не доказывает успешную активацию клиента.
- **Поддержка:** RU/EN отчёты, негативные сценарии, контроль хешей, provenance и кроссплатформенный CI.
