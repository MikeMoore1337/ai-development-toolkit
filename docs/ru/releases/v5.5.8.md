## Реализация и пределы подтверждений

Native Learning v2 - **помощник ручного рассмотрения**, а не непрерывное обучение модели. Для исходного адаптера MCP `0.1.19` ранее подтверждались обнаружение/вызов MCP и положительные/отрицательные синтетические результаты. Реальная активация **Native Agent Skill в Codex - NOT_VERIFIED**. Измеряемое улучшение качества ответов модели - **NOT_MEASURED**. Результат MCP никогда не означает согласование владельца: `owner_approval=NOT_GRANTED`, `practice_auto_promotion=false`, `approved_practices_written=0`. Для каждой практики требуются отдельное рассмотрение доказательств, явное утверждение, проверенный diff/PR и CI. Автопродвижения нет.

В исходниках: Toolkit-кандидат `5.5.8`, Personal MCP source adapter `0.1.19`, исходники плагина ChatGPT `0.1.5`. Минимальная версия по `MANIFEST.json.chatgpt_personal_live.min_plugin_version=0.1.5`. Версии компонентов **независимы**. Публикация GitHub Release сама по себе **не обновляет, не устанавливает, не активирует и не перезапускает** MCP; не обновляет приватный плагин ChatGPT и не доказывает активность навыка в клиенте. Новых обязательных служб и миграций БД при этой подготовке нет.

## Обновление после публикации (не раньше)

1. Убедиться, что GitHub Release `v5.5.8` **действительно опубликован** на утверждённом SHA, архивная проверка успешна, а тег совпадает с версией манифеста. Использовать отдельную чистую копию; не затирать рабочие изменения.
2. В этой копии выполнить `git fetch --tags origin`, затем `git switch --detach v5.5.8`. Проверить `git rev-parse HEAD`, `MANIFEST.json.version`, `python scripts/verify_checksums.py` и `python scripts/validate_provenance.py --mode release`. Файл `SHA256SUMS.txt` описывает отслеживаемые исходники; архивная проверка дополнительно подтверждает полное совпадение списка файлов.
3. Для установленных в **конкретный проект** навыков использовать [статус, предпросмотр, применение и откат Skill Manager](../UPDATING.md). Незарегистрированные файлы не присваиваются без разрешения; выбор версии Toolkit не является миграцией чужого проекта.
4. Установленный **отдельно** Personal MCP обновлять только по проверенной [инструкции](../MCP_INSTALL.md), с контролем `toolkit_info`, версии адаптера и переподключением клиента при необходимости. Приватный плагин ChatGPT обновляется отдельно через свой механизм доставки/Plugin Creator. Публикация тега не выполняет ни одно из этих действий.

## Обратимый откат

Для возврата исходников сохранить чистую копию `v5.5.7` и в ней выполнить `git fetch --tags origin`, `git switch --detach v5.5.7` после проверки локальных изменений. **Не выполнять принудительный reset рабочего проекта и не менять старые теги.** Установленные в проект навыки откатываются отдельно через предпросмотр и процедуру Skill Manager. Обновлённый MCP и приватный плагин имеют **собственные** процедуры отката и переподключения. Для Native Learning достаточно отбросить результат read-only preview: практика автоматически не применялась.
