# Product Discovery: от идеи к MVP и PRD

[English](../PRODUCT_DISCOVERY.md) | [Каталог навыков](SKILLS_CATALOG.md) | [Профили](CURATED_SKILL_PACKS.md)

Используйте, когда нужно решить, **что разрабатывать, для кого и как проверить полезность**, прежде чем писать код. Необязательный профиль `product-discovery` добавляет один специализированный навык и повторно использует существующие навыки постановки задачи и проверки источников. Не нужны платный AI API, новый установщик или учётная запись.

## Начало без терминала

В клиенте, который умеет читать Toolkit, достаточно написать:

> Используй https://github.com/MikeMoore1337/ai-development-toolkit, чтобы превратить мою идею учёта домашних расходов в минимальный MVP и короткий PRD. Не меняй код и не создавай файлы.

Агент должен описать сегмент и проблему, отделить факты от допущений, предложить опровергаемые гипотезы, явно включённые и исключённые возможности MVP, проверяемые требования и осмысленные метрики, а также следующий шаг. Если клиент не умеет читать репозиторий, ему потребуется текст соответствующего навыка; это не доказательство автоматической активации. Для открытого локального проекта ссылка на его GitHub не нужна.

**PRD** - описание предлагаемого продукта, а не готовая программа, доказанный спрос или разрешение на реализацию. Персоны без интервью - гипотетические. Отсутствующая базовая метрика остаётся `UNKNOWN`. Не требуется передавать персональные данные.

## Для опытных пользователей и дополнительная установка

Можно запросить журнал доказательств, очередь продуктовых гипотез, определения метрик, связи R-ID/AC-ID и передачу результатов в #54 (управление проектом), #55 (бизнес/системный анализ) и #56 (UX/UI). [Канонический навык](../../extensions/product/skills/product-discovery/SKILL.md) содержит договорённости и синтетические примеры.

Существующий менеджер поддерживает безопасный предварительный просмотр:

```bash
python scripts/skill_manager.py catalog --profile product-discovery
python scripts/skill_manager.py install --target /path/to/project --profile product-discovery
```

Установка необязательна; только `--apply` разрешает установку в выбранный пользовательский проект. Для других проектов Toolkit остаётся только читаемым источником. По умолчанию PRD возвращается в чат. Файлы в Toolkit или локальных копиях автоматически не создаются.
