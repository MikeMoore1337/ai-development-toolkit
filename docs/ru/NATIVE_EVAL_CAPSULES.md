# Нативные капсулы и квитанции проверок Toolkit (#437)

В Toolkit встроены **18 оригинальных неизменённых файлов** `affaan-m/ECC@25278e7d7b6cf6e6a4e7a6c8e10f14ff22f0eb5b` как **необязательная автономная библиотека свидетельств**, расположенная в `third_party/ecc-v2.2.3/eval-harness/`. Отдельная установка ECC, его CLI, MCP, плагина, агента или sidecar не требуется. Оригинальная лицензия MIT сохранена в `third_party/ecc-v2.2.3/LICENSE`; контроль Git blob и SHA256 - в `SOURCE_SNAPSHOT.json`. Файлы исходной библиотеки и тестов не модифицированы. За оценку качества результатов по-прежнему отвечает штатный `scripts/skill_eval.py`.

## Возможности

- Канонические JSON-конверты, разрешённые поля, защита от случайной записи секретов и пять типов событий
- Локальный дописываемый журнал с цепочкой SHA-256 и детерминированной проверкой изменений
- Квитанции с отпечатками журнала, артефакта и проверки, обнаружение подделки и устаревшего состояния
- Воспроизведение **только по фикстурам**, без обращения к реальному исполнителю; эффекты SE3/SE4 запрещены
- Статический анализ вариантов и принудительный отказ от запуска кандидата: `gate.isolation_required`

**Ограничение:** цепочка хешей обнаруживает изменения *предъявленной* истории, но не защищает от полной подмены всех файлов без внешнего доверенного свидетеля. Проверенная квитанция не доказывает истинность оценки, результат работы модели или разрешение на публикацию.

### Ручное использование (достаточно локального Node.js)

В доверенном checkout Toolkit, с уже подготовленной в разрешённом окружении капсулой:

```text
node scripts/native_eval_capsules.js capsule verify /local/capsule
node scripts/native_eval_capsules.js capsule project /local/capsule
node scripts/native_eval_capsules.js receipt build /local/capsule --artifact /local/approved/artifact
node scripts/native_eval_capsules.js receipt verify /local/receipt.json /local/capsule --artifact /local/approved/artifact
```

Операции `verify` только читают файлы. Команды `project` и `receipt build` **явно записывают `projection.json`** внутри указанной капсулы. Не использовать без разрешения на неизвестных или производственных путях. Обёртка Toolkit не выполняет агента, не запускает пример, фоновую запись наблюдений, хуки, сетевые запросы и не изменяет проект. Для записи события требуется отдельное явное разрешение доверенного вызывающего кода; воспроизведение не вызывает реальный инструмент. Секреты и историю переписок передавать запрещено.

## Тестирование и ограничения

`tests/test_native_ecc_eval_capsules.py` проверяет совпадение каждого оригинального Git blob и SHA256, запускает пять неизменённых исходных Node.js тестовых наборов при наличии Node.js, а также проверяет подделку квитанции, изменение журнала, отсутствующую фикстуру, запрет SE4, отказ CLI и отсутствие побочных файлов. Прохождение тестов подтверждает **только локальный исходный код и синтетическое поведение**, не активацию в Codex Desktop. Если Node.js отсутствует, runtime остаётся **NOT_VERIFIED**, даже при успешной проверке исходников.

Нет Codex CLI, Claude CLI, платных API, фоновых процессов и обязательной установки ECC. Откат - обычный PR, удаляющий необязательный модуль и обёртку, без изменений глобальных настроек. Новый версионированный релиз Toolkit требует отдельной приёмки владельца.
