# Model Switching Adapters - клиентские адаптеры (Issue #357)

[English](../MODEL_SWITCHING_ADAPTERS.md) | [Универсальный советник](ADAPTIVE_EXECUTION_ADVISOR.md)

`scripts/model_switching_adapters.py` - **адаптер с функциями, предоставленными клиентом**, а не новый AI-провайдер, оболочка Codex CLI, платный API или отдельный сервер. Он не пытается вызывать модели без интерфейса исполнения, разрешённого пользователем.

## Контракт клиента

Нужны точные `request` и `consent` из советника, выбранная пользователем модель и состояние одной задачи: `task_id`, `inventory_revision`, `calls_used`, `revoked`. Настоящий клиент самостоятельно защищает эти данные и проверяет доступные по аккаунту модели.

- `snapshot()` - возвращает актуальный перечень моделей, версию проверки, возможность переключения/делегирования и подтверждение отсутствия дополнительных расходов. Адаптер **повторно сверяет данные перед каждым запуском**.
- `invoke(model_id, context, method)` - выполняет работу через **существующий разрешённый механизм клиента**. Если подтверждено делегирование, применяется `delegate`; иначе только при поддержке переключения - `switch`.
- `restore(primary_model)` - обязателен при переключении главной модели. Если восстановление не подтверждено, результат `PRIMARY_RESTORE_NOT_VERIFIED`.
- В рекомендательном режиме требуется **отдельное согласие на каждый вызов**. В автоматическом режиме применяются заранее выбранные модели и ограничение `max_extra_calls` от 1 до 10 для текущей задачи.
- `context` должен содержать только минимально необходимый согласованный контекст; адаптер его не журналирует. При сбое возвращается `HOST_CALL_FAILED`, попытка учитывается, повторного скрытого обращения нет.
- `EXECUTED_VERIFIED_BY_HOST` означает, что **сам клиент** сообщил о фактически использованной модели. Это не независимое подтверждение и не обещание улучшения качества.

## Среды

| Клиент | Советник | Автоматическая работа в текущей поставке |
| --- | --- | --- |
| Codex | Да | Только через предоставленные клиентом функции; реальная версия НЕ ПРОВЕРЕНА |
| Claude Code | Да | Аналогично, требуются подтверждённые локальные возможности |
| ChatGPT / Claude web | Текстовые рекомендации | Без публичного интерфейса смены модели - только ручной вариант |
| DeepSeek / Qwen / другие | Текстовые рекомендации | Возможности неизвестны до фактической проверки клиента |

Не угадывать доступные модели по общим спискам в интернете. Не подменять неизвестные лимиты оценками. Если каталог или способ исполнения недоступен, работать на текущей модели без дополнительных обращений.

## Проверки и пределы готовности

`python -m unittest tests.test_model_switching_adapters -v`. Тесты используют синтетические функции без реального запуска моделей, платных API, доступа к ключам, изменения настроек и файлов проектов.

**Реальная приёмка #357 пока не подтверждена:** нужны проверка на установленных Codex/Claude Code, версия клиента, фактически наблюдаемая модель, возврат к основной, поведение при исчерпании лимитов и проверка качества. Офлайновые тесты не дают оснований закрывать задачу как действующее автоматическое переключение.
