# Рекомендации регрессионных проверок по изменениям (офлайн)

Детерминированный инструмент для планирования проверок по путям изменённых файлов. Дополняет существующий `change-impact-analysis`, но **не** запускает тесты, не читает содержимое изменённых файлов, не строит граф вызовов и не изменяет проект.

Создайте JSON-массив относительных путей, например:

```json
["src/auth/session.py", "db/migrations/001.sql", "frontend/screens/workout.tsx"]
```

Выполните `python scripts/change_impact_advisor.py --paths-json changed.json`.

Результат включает уровень риска, затронутые области, обязательные категории регрессии с путями-основаниями, статусы `NOT_RUN` и `NOT_OBSERVED`. Для авторизации предлагаются отрицательные проверки прав; для миграций - прямой и обратный переход и целостность данных. Неизвестные пути требуют ручного изучения, а не автоматически объявляются безопасными. Это **не замена** анализу diff, проверке потребителей контрактов и настоящим тестовым запускам.

Без платных API, установок и вызовов моделей. Задача: [#191](https://github.com/MikeMoore1337/ai-development-toolkit/issues/191).
