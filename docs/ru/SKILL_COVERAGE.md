# Диагностика покрытия задачи локальными навыками (Issue #199)

[English](../SKILL_COVERAGE.md) | [MCP](../../scripts/toolkit_mcp.py) | [Проверки маршрутизации](../SKILL_ROUTING_EVALS.md) | [Внешние методики](../EXTERNAL_METHODS_ADOPTION.md)

В `scripts/toolkit_mcp.py` добавлен read-only MCP-инструмент `toolkit_assess_skill_coverage` с обязательным аргументом `query` (строка длиной от 1 до 500 символов). Существующий `toolkit_route_task` дополнительно возвращает объект `skill_coverage`. Это **локальная диагностика исходников**, а не доказательство полноты навыков, семантического совпадения или их фактической активации в Codex/Claude/ChatGPT.

| `coverage` | Значение | Дальнейшее действие |
|---|---|---|
| `FOUND_LOCAL` | Запрос точно совпал с именем доступного навыка, объявленного в манифесте | Прочитать навык, проверить применимость и разрешения |
| `AMBIGUOUS` | Найдены лексические совпадения; достаточность навыка не установлена | Оценить кандидатов и требования к задаче |
| `MISSING` | Не найдено лексических совпадений | Зафиксировать пробел, при разрешении отдельно искать внешние источники |

Имена и числовые оценки кандидатов - **подсказки на основе совпадения слов**, не показатель эффективности. `MISSING` не доказывает отсутствие подходящего по смыслу навыка; перефразирования и русскоязычные запросы могут давать ложноотрицательные результаты. Резервный профиль `general` не означает, что профиль покрывает специализированную задачу.

Всегда возвращаются `external_skill_search=NOT_RUN`, `external_skill_install=NOT_AUTHORIZED`, `client_activation=NOT_OBSERVED`, `requires_review=true`. Текст запроса - недоверенные данные, его инструкции не выполняются. Реализация не устанавливает плагины, не подключает новых провайдеров, не обращается к Agensi, не использует платные API и не загружает внешние файлы.

## Проверки

```bash
python -m unittest tests.test_toolkit_mcp -v
python scripts/validate_pack.py
python -m unittest discover -s tests -v
```

Тесты проверяют точное локальное имя, неоднозначную задачу, отсутствие совпадений, ограничения входа, текст prompt injection как данные и отсутствие записи в проект. Это проверки исходников, **не** испытания реального AI-клиента. Фактическое обнаружение и вызов MCP-инструмента в Codex нужно проверить отдельно.
