# Четыре воспроизводимых примера Toolkit без платных API

[English](../VERIFIED_EXAMPLES.md) · [Начало работы](BEGINNER_WORKFLOW.md) · [Возможности клиентов](CLIENT_CAPABILITIES.md)

Команды работают с исходниками Toolkit и Python 3.12+ при установленных зависимостях разработки. Они **не** устанавливают навыки, не вызывают модель, не читают приватный проект и не выполняют деплой. В CI `tests/test_verified_examples.py` выполняет все четыре команды и проверяет их результаты. Успешный CI доказывает работу на соответствующем runner и SHA, **не** поведение любого AI-клиента.

Запускайте из корня репозитория после `python -m pip install -r requirements-dev.txt` (загружает закреплённую зависимость PyYAML; если она уже есть, переустановка не обязательна). Для Windows/Python 3.14 используйте `py -3.14` вместо `python`.

## Пример 1 — список профилей без установки

```bash
python scripts/adt.py --json profile list
```

Ожидается JSON с объектом `profiles`. Навыки не устанавливаются, реальные вызовы клиента не выполняются. Проверяется только CLI; активация в клиенте: **NOT_TESTED**.

## Пример 2 — проверка существующих лексических сценариев

```bash
python scripts/skill_routing_eval.py --strict
```

Код 0 означает прохождение текущего тестового набора. Это **не** проверка семантической точности LLM или полезности навыков. AI-задача в клиенте: **NOT_RUN**.

## Пример 3 — диагностика маршрутизации RU/EN

```bash
python scripts/skill_routing_eval.py --holdout fixtures/skill_routing_untuned_20261024.json
```

Ожидается JSON с `count=16` и разбивкой по языку и типу запроса. Частичные совпадения не превращаются в провал релиза или подтверждённую точность. Независимая человеческая разметка: **NOT_VERIFIED**, фактическое использование навыка: **NOT_OBSERVED**.

## Пример 4 — проверка синтетического QA-отчёта

```bash
python scripts/validate_qa_orchestration.py fixtures/qa_orchestra_valid.json
```

Ожидается подтверждение внутренней согласованности **синтетического** отчёта. Браузер, тесты приложения, агенты, БД и целевое окружение не запускались. Реальные тесты проекта: **NOT_RUN**.

## Доказательства и ограничения

- `tests/test_verified_examples.py` действительно вызывает все четыре команды в CI и проверяет отсутствие записи. `tests/test_supply_chain_pins.py` проверяет SHA закреплённых GitHub Actions и точную версию PyYAML.
- `uses` в GitHub Actions закреплены по полным **SHA коммитов** официальных тегов на 24.10.2026. Неизменяемая ревизия защищает от незаметного изменения тега, но **не** является проверкой криптографической подписи или гарантией безопасности кода.
- В `requirements-dev.txt` закреплена `PyYAML==6.0.3` для единообразного выбора зависимости в Linux, macOS и Windows (включая Python 3.14). Установка использует настроенный индекс пакетов: происхождение всех wheel и полная воспроизводимость окружения **не доказаны**.
- Офлайн-примеры не подтверждают реальные действия клиентов, экономию токенов или отсутствие проблем в продуктивном проекте. Для рабочего репозитория действуют его правила доступа, QA и выпуска.
