# Diagram Design: безопасный пилот архитектурных схем (Issue #265)

[English guide](../DIAGRAM_PILOT.md)

Этот эксперимент **не устанавливает** [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design), не переносит его исходники и не создаёт новый постоянный навык агента. Из проекта заимствованы общие идеи: читаемая композиция, статический HTML со встроенным SVG и видимые источники фактов. Реализация `scripts/diagram_pilot.py` написана отдельно на стандартной библиотеке Python.

## Зачем это нужно

Mermaid удобен как исходная текстовая схема и остаётся основным простым вариантом. Пилот дополнительно создаёт **переносимый автономный HTML**, который можно открыть без сети. Задача - проверить полезность для архитектурных обзоров Toolkit, Hermes, YFC и Second Brain, не добавляя в их приложения зависимости.

## Пример для новичка

1. Открой `docs/examples/diagram-pilot.synthetic.json`. Это выдуманная архитектура, **не** данные действующих проектов.
2. Каждый узел содержит `id`, `label`, `column` от 0 до 3 и `evidence`; каждая связь содержит `from`, `to`, `label` и `evidence`. Evidence - утверждение автора входа, **не** доказательство, проверенное инструментом.
3. Выполни в корне Toolkit (Python 3.10+):

```bash
python scripts/diagram_pilot.py docs/examples/diagram-pilot.synthetic.json --output example-diagram.html
```

4. Открой `example-diagram.html` в браузере. Посмотри подписи узлов, стрелки, масштабирование и раскрываемые источники. Скрипт не перезаписывает готовый файл.

Тесты: `python -m unittest tests.test_diagram_pilot -v`.

## Контракт и ограничения

- Версия JSON строго `1`; максимум 16 узлов и 28 связей, слева направо по столбцам `0..3`. Обратные связи и циклы в этом пилоте **не поддерживаются** - для них оставь исходную Mermaid/описание, не искажай архитектуру.
- Выход: статический HTML+SVG, без JS, внешних шрифтов, картинок, сетевых запросов и платных API. CSP блокирует внешние ресурсы, строки экранируются.
- `evidence` обязателен для всех узлов и стрелок. Для реальных проектов указывай проверенные пути/commit/Issue и отделяй подтверждённые связи от предположений. Генератор **не проверяет** существование источника, не извлекает сведения из GitHub и не определяет права доступа.
- HTML может содержать текст из JSON: **не публикуй** артефакты с приватной информацией или секретами. В репозитории только синтетическая фикстура.
- Схема **не является** фактическим снимком production, визуально одобренным макетом или доказательством исполнения агента. Пока сравнение с Mermaid, ручной UX/визуальный осмотр и пилот на реальных проектах не проведены: `VISUAL_NOT_REVIEWED`, `EFFECTIVENESS_NOT_TESTED`.
- Никаких изменений `MANIFEST.json`, клиентской маршрутизации, UX/UI Design Orchestra, workflow развертывания или production.

## Изменения после проверки мобильного вида

HTML теперь отображает схему в области с **горизонтальной прокруткой**, не сжимая текст до нечитаемых 6 px. Можно прокручивать пальцем, трекпадом или перемещать фокус клавиатурой на область схемы (Tab). Подсказка показана над рисунком, полный перечень происхождения узлов и связей остаётся ниже.

Подписи стрелок видны непосредственно на линии; для длинных (>14 символов) выводится сокращённая подпись с полным текстом в `<title>` SVG и в списке источников. Повторные связи между одной парой блоков теперь отклоняются, так как в пилоте их подписи могут перекрываться. На мобильном экране нет требования уместить все блоки в ширину телефона - сохраняется нормальный размер текста.

**Предстоит проверить вручную:** Chrome desktop и мобильный режим 390 px, горизонтальную прокрутку, переполнение узлов с длинными именами, контраст, подписи на диагональных стрелках и клавиатурный фокус. Автоматические тесты подтверждают наличие структуры, но не качество компоновки.

## Пример на подтверждённой архитектуре Hermes

Для сравнения с синтетическим примером добавлена модель `docs/examples/hermes-research.source.json`. Она построена по доступным 23.10.2026 исходникам `MikeMoore1337/hermes`: `research_scout/europe_pmc.py`, `research_scout/crossref.py`, `research_scout/daily_digest.py` и `research_scout/README.md`. На схеме показаны **только подтверждённые зависимости научного контура**, без секретов, сетевых конфигураций и утверждений о нынешнем состоянии production.

```bash
python scripts/diagram_pilot.py docs/examples/hermes-research.source.json --output hermes-research-diagram.html
```

Сравни скриншоты на 390 px и широком экране с исходным текстовым Mermaid. Это иллюстрация подтверждённых связей в коде, а не результат автоматического аудита развёртывания.
