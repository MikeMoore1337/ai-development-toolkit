## Пересечение с Toolkit

`scripts/profile_metrics.py` (#194) анализирует объём профилей/навыков, но не проверяет структурные проблемы в `AGENTS.md` и `CLAUDE.md`. Добавлен **отдельный необязательный отчёт только для чтения**, а не второй Skill Manager и не глобальный установщик.

Запуск: `python scripts/audit_agent_instructions.py --root .`. Вывод JSON в stdout. Исходные тексты, ключи и полные найденные правила не печатаются. Файлы и настройки **не изменяются**.

Находки: `DUPLICATE_CROSS_FILE_RULE` (точное повторение нормализованного правила между файлами), `STALE_OR_UNSAFE_REFERENCE` (встроенная ссылка в форме `path.ext:line` не существует/выходит за границу), `UNSAFE_FILE`, `TOO_LARGE`, `UNREADABLE`. Повторы не доказывают логический конфликт, а отсутствие находок не доказывает отсутствие конфликтов, prompt injection или устаревших рекомендаций. Использовать результат как подсказку для ручной ревизии.

Границы: только `AGENTS.md` и `CLAUDE.md`, до 256 файлов и 256 КиБ/файл; симлинки и сгенерированные каталоги пропускаются, root-symlink запрещён. Никаких LLM/API, сети, hooks, автоустановки, автоматического сокращения правил и правок в чужих репозиториях. Сохранять глобальные owner gates; «все root инструкции до 100 строк» - эвристика исходного проекта, не обязательная политика Toolkit.

Проверка: `python -m unittest discover -s tests -p test_audit_agent_instructions.py -v`, затем стандартный CI. Откат: удалить этот независимый необязательный скрипт, его тесты и документацию; другие инструменты не зависят от него.
