# Prompt Refinement and SEO

[Русская версия](ru/PROMPT_AND_SEO_SKILLS.md)

Two portable, optional skills requiring no paid API:

| User request | Profile | Output |
| --- | --- | --- |
| "Turn my rough notes into a good prompt" | `prompt-refinement` | One usable prompt; no execution of target task |
| "Audit website SEO" | `seo-audit` | Evidence-based issues, priorities and verification |

Local installation uses existing **Preview -> Apply -> Status**. ChatGPT and MCP should choose the matching skill by user intent; they cannot assume installed plugin code updates automatically from GitHub. Only an actually verified SHA and CI allow the on-demand live-refresh claim. No writes to another project without authorization.
