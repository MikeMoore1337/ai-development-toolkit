# English translations of Russian-origin Toolkit guides

[Russian documentation](../ru/README.md) | [Language policy](../LANGUAGE_POLICY.md) | [English README](../../README.md)

Several original Toolkit guides were authored in Russian. This directory provides English **human-facing** translations of those documents while retaining one canonical source for each.

| Topic | English translation | Russian original |
| --- | --- | --- |
| Adapting to a new project | [Adaptation](ADAPTATION.md) | [Адаптация](../ADAPTATION.md) |
| Choosing skill packs by project | [Integration matrix](INTEGRATION_MATRIX.md) | [Матрица подключения](../INTEGRATION_MATRIX.md) |
| Portability test scenarios | [Evaluation scenarios](PORTABILITY_EVAL_SCENARIOS.md) | [Сценарии проверки](../PORTABILITY_EVAL_SCENARIOS.md) |
| Prompt for implementation tasks | [Task prompt](TASK_PROMPT_TEMPLATE.md) | [Шаблон задачи](../TASK_PROMPT_TEMPLATE.md) |
| Make Feature user guidance | [Make Feature guide](../MAKE_FEATURE_INTEGRATION.md) | [Руководство](../ru/MAKE_FEATURE_INTEGRATION.md) |

**Scope:** Commands, identifiers, cautionary language and acceptance criteria are preserved. The translations do not constitute a second runnable `SKILL.md`, evidence that a client activated a skill, a new legal authorization, or measured performance.

The [source revision checks](../ru/SOURCE_REVISIONS.json) can warn when an original document changes, but cannot establish meaning or accuracy. See [language policy](../LANGUAGE_POLICY.md). Other technical documentation is still untranslated; do not interpret the index as 100% coverage.
