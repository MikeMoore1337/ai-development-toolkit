# Шаблон задачи для ChatGPT / Codex

[English version](en/TASK_PROMPT_TEMPLATE.md)

**Контекст:** [репозиторий и задача]. **Цель:** [наблюдаемое изменение].

1. Сначала проверь актуальный код, задачу, правила репозитория и зависимости. Не доверяй устаревшему описанию состояния.
2. Сформулируй критерии приёмки и границы; используй только необходимые роли и навыки.
3. Реализуй минимальное законченное изменение, сохраняя действующие контракты и проектные соглашения.
4. Протестируй изменённое поведение существующими инструментами проекта; проверь негативные и регрессионные сценарии по риску.
5. Выполни самопроверку, назови команды, реальные результаты и непроверенные места.
6. Выполни commit/PR/merge/deploy только если они входят в запрос и разрешены фактическими правилами и полномочиями проекта. Не выдавай план за сделанную доставку.
7. Итог: изменения, доказательства, ссылка на PR/commit (при наличии), статус merge/deploy (если применимо), ограничения.
