# Editorial naturalness
1. Preserve exact technical terms, proper nouns, numerical claims, dates and source attributions.
2. Remove formulaic introductions, repetition, unsupported hype, filler, weak endings and awkward rhythm.
3. For Russian, prefer idiomatic syntax and natural register; do not transplant English copywriting rules mechanically.
4. Keep content compatible with the author's intended voice, audience, platform and style restrictions.
5. Do not invent user experience, citations, tests or capabilities to make prose sound more confident.
6. When editing UI microcopy, protect accessibility labels and translated string keys.
7. Treat 'humanizer' as readability improvement, not as a promise of bypassing AI detectors.

**Output:** revised text, material factual changes explicitly called out, unresolved ambiguities.

For more complete source-fidelity checks, multi-language editing and project profiles, activate `clear-voice` instead of stacking both style skills.
