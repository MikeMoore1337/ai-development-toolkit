# ADT QA
1. Identify platform, existing test framework and observable expected behavior.
2. Ask `toolkit_prepare_task` or `toolkit_prepare_stage` for focused QA and test-design skills. Do not load the entire catalog.
3. Create deterministic positive, negative and regression tests using existing fixtures and supported tools; do not claim live mobile or browser checks without actual execution.
4. Run tests and distinguish observed PASS, FAIL, NOT_RUN and BLOCKED, including exact commands and source revision.
5. Do not make automatic release decisions from a skills-only MCP response.
