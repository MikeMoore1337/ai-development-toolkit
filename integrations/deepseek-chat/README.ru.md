# AI Development Toolkit в DeepSeek Chat

[English](README.md) | [Все интеграции](../../docs/ru/INTEGRATIONS.md)

Инструкция относится к **обычному DeepSeek Chat в браузере или приложении**, не к DeepSeek Harness и не к платному API. Установка плагина или MCP для обычного чата не подтверждена.

## Работа без терминала

1. Откройте официальный [DeepSeek Chat](https://chat.deepseek.com/).
2. Передайте задачу и ссылку на Toolkit из примера ниже. Если чат не может **фактически прочитать** GitHub, приложите только необходимые открытые `SKILL.md` и дополнительные инструкции одной ревизии.
3. При необходимости передайте разрешённый фрагмент проекта или архив. Убедитесь, что файлы доступны самому чату. Не отправляйте секреты и конфиденциальные материалы.
4. Попросите перечислить реально прочитанные источники, доступные файлы, выполненные действия, фактически проведённые проверки и ограничения.

```text
Используй https://github.com/MikeMoore1337/ai-development-toolkit
как источник инструкций по разработке и тестированию, только для чтения.
Задача: <ОПИШИТЕ ЗАДАЧУ>.
Прочитай только необходимые навыки, если есть реальный доступ.
Укажи прочитанные файлы и точный SHA, если он проверен.
Если GitHub и вложения недоступны, прямо сообщи об этом.
Не утверждай, что навыки установлены, код выполнен, файлы изменены,
агенты запущены или тесты пройдены без подтверждения.
Не используй платные API.
```

## Проверка результата и ограничения

- **URL_READ**: содержимое ссылки реально получено; сама отправка адреса ничего не подтверждает.
- **GUIDANCE_ONLY**: текст `SKILL.md` использован как инструкция, но не установлен как нативный Skill.
- **L4/L5/L6** (обнаружение/активация/измеренная польза нативного Skills): **NOT_TESTED / NOT_TESTED / NOT_MEASURED** для Toolkit в DeepSeek Chat.
- Историческая успешная проверка ZIP + URL от 20.10.2026 - **OWNER_REPORTED_PASS**, без независимых журналов клиента.
- DeepSeek документирует чат и загрузку файлов, но доступность GitHub, архива, инструментов и операций с файлами определяется конкретным сеансом.
- Этот способ не требует DeepSeek API, покупки подписки и сам по себе не изменяет пользовательский проект.

Официальный источник: [представление DeepSeek App](https://api-docs.deepseek.com/news/news250115/). Подтверждена документация, **не реальная активация в DeepSeek**.
