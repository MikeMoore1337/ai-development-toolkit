# Интеграции AI Development Toolkit

**Два равноправных способа подключения к единому каталогу навыков и ролей Toolkit.** Выбирайте по рабочей среде и разрешённому доступу к исходникам проекта:

| Интеграция | Что предоставляет | Установка |
| --- | --- | --- |
| **[Плагин ChatGPT](chatgpt-plugin/README.ru.md)** | Подбор и использование встроенных либо доступных проверенных инструкций Toolkit по задаче, без локального сервера | Через ChatGPT при поддержке плагинов (Windows, Linux, macOS и поддерживаемые мобильные клиенты) |
| **[Локальный MCP для Codex](personal-mcp/README.ru.md)** | Маршрутизация задач, загрузка недостающих инструкций и ролей для рабочей области Codex | Windows, Linux и macOS; доступно автообновление локальной библиотеки |

Обе интеграции позволяют использовать навыки без копирования файлов в проект. Ни одна из них не даёт неоговорённого доступа к данным, не изменяет проект автоматически и не требует платного API. Плагин и MCP **независимы** и не требуют обязательной установки друг друга.
