# SEO audit - evidence and reproducibility

| Category | Check |
| --- | --- |
| HTTP and discovery | Status codes, redirects, navigation, XML sitemap |
| Crawling/indexing | robots.txt, noindex headers/tags, canonical, confirmed Search Console coverage |
| Rendering and mobile | Server-rendered versus rendered HTML, mobile content, Core Web Vitals measurements |
| Pages and intent | Title, headings, meta description, useful accurate content, internal links, images |
| Rich results | Page-appropriate structured data and documented eligibility |
| Special cases | Local business accuracy, ecommerce variants, hreflang/international pages |
| Outcome | Real Search Console clicks/impressions and conversions; baseline period |

Use statuses `CONFIRMED`, `HYPOTHESIS`, `NOT_VERIFIED`. Do not claim indexing, rankings or SEO improvement without observations.
