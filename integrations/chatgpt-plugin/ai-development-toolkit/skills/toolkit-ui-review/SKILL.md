# Toolkit UX/UI review
Start through `toolkit-task-router`. Use UX/UI Design Orchestra for new sites and substantive redesigns, reading its actual `SKILL.md` and workflow references when tools permit. Develop three **structurally distinct** composition hypotheses and, when the user's output permits visual assets, actually generate and compare three low-fidelity visuals. Reject interchangeable generic SaaS layouts. Follow product-specific visual direction, grounded copy, accessibility and reduced-motion needs. Choose one direction and provide desktop/mobile evidence before asking for visual acceptance; a text-only design is not a visual comparison. Never edit the production UI or claim external specialist-agent execution without verification and approval. Small bounded fixes of already approved components need not restart the full orchestra.
