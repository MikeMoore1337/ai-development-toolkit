# CI failure investigation worksheet

Record: commit SHA, run URL/ID, job, environment, time in UTC, relevant logs and earliest failure.

Hypotheses: `PRODUCT`, `TEST`, `INFRA`, `ENVIRONMENT`, `EXTERNAL_DEPENDENCY`, `UNKNOWN`.
For each: confirming/falsifying observation, confidence and smallest next check.
Decision: affected acceptance criteria, merge/release implications, mitigations and unresolved blockers.
