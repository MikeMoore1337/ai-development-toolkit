# Сделай мне функцию · make-feature

Адаптивный оркестратор: короткий запрос → выбранное решение → контракт и план → реализация → независимая приёмка. Для простого запроса короткий маршрут; глубокий разбор подключается по неопределённости и риску.

- [Маршрут и выбор глубины](SKILL.md).
- [Установка одному текущему агенту](INSTALL.md).
- [Четыре основных рабочих документа](references/documents.md).
- [Проверки и границы доказательств](TEST-REPORT.md).
- [Происхождение](SOURCES.md).

Python3.10+, stdlib. workspace.py сохраняет запрос/ссылки; budget.py считает делегации/исправления и elapsed; state.py дополнительно хранит зависимые execution-фазы и актуальность проверок. Скрипты не исполняют LLM и не обещают измерить недоступный usage или продолжить работу после остановки runtime.

Запрос: «Сделай мне функцию: …». Проверка пакета: `python3 -m unittest discover -s tests -v`. demo.py — синтетический пример ledger, не продуктовый тест. Локальный пакет и персональная выдача на платформе — отдельные этапы.
