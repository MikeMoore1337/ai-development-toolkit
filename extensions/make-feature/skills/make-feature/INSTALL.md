# Установка

1. Если получен архив, проверь тип и содержимое: `file ARCHIVE`, `tar -tzf ARCHIVE`. Ответ с ошибкой вместо gzip не распаковывай. Персональную лицензию платформы читай из `LICENSE.txt`, если она входит в выданную копию.
2. Распакуй в новую временную папку. Для архива с единственным корневым каталогом: `tar -xzf ARCHIVE -C TEMP --strip-components=1`; для плоского — без `--strip-components`. Выбор делай по фактическому списку файлов. Прочитай SKILL.md и scripts до исполнения.
3. Определи текущего клиента и его активный профиль; выбери только один каталог:

| Клиент | Каталог |
|---|---|
| Hermes | `HERMES_HOME/skills/productivity/make-feature` — фактический home активного профиля |
| Codex | `~/.agents/skills/make-feature` или каталог, заданный текущей конфигурацией |
| Claude Code | `~/.claude/skills/make-feature` |

4. Перед заменой существующей установки сохрани её целиком в отдельном каталоге резервной копии. Не объединяй разные версии пофайлово; не переноси проектные журналы и данные в общий каталог навыков. Установка не изменяет провайдеры, доступы или другие навыки.
5. Скопируй весь проверенный пакет в выбранный каталог. Запусти там `python3 -m unittest discover -s tests -v`. При ошибке сохрани новую копию для разбора и восстанови прежнюю.
6. В новой сессии проверь загрузку `make-feature` средствами клиента и запросом «Сделай мне функцию». Прочитанный файл и обнаружение навыка — разные проверки; зафиксируй фактический результат.

Само копирование не запускает продуктовую работу и ничего не публикует. Для приватного репозитория нужен предоставленный доступ или выданный архив; публичный git clone не обещается.
