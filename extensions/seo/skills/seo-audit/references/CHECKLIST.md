# SEO evidence checklist

| Area | Check | Evidence |
| --- | --- | --- |
| Crawl | URLs, sitemap, robots, links | Actual found URLs/response |
| Index | noindex, canonical, status, redirects | HTML/HTTP and Search Console if available |
| Content | Title, headings, intent, usefulness, alt | Actual page content |
| Structure | Internal links, duplicates, pagination | Inspected URLs |
| Speed | Mobile/Core Web Vitals | Dated measurements or NOT_MEASURED |
| Structured data | Appropriate real JSON-LD | Markup and eligibility check |
| Special | Local NAP, ecommerce, hreflang | Verified on-page/business facts |
| Outcomes | Clicks, impressions, index coverage | Dated verified measurements |

**Output:** Priority | URL | Evidence | CONFIRMED/HYPOTHESIS/NOT_VERIFIED | Hypothesized impact | Fix | Validation.

Never infer rich result or first position from valid structured data.
