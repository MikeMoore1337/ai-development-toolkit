# SEO audit

Use for: «Проверь SEO сайта», «Почему страницы не индексируются?», «Улучши SEO магазина», "Technical SEO audit". Not for paid ads or guaranteed Google rank.

1. Establish the exact site/pages or supplied HTML, audience, locale, language, goals and **actual available access**. Without access, provide an inspection plan, not fictional findings.
2. Label each result `CONFIRMED` (actually observed), `HYPOTHESIS` (requires check), or `NOT_VERIFIED` (no evidence). Include affected URL, source, date and method. Do not invent rankings, indexed pages, keyword volume, traffic, impressions, conversions or metrics.
3. **Technical:** HTTP statuses, redirects, `robots.txt`, `noindex` (meta or X-Robots-Tag), `canonical`, duplicates, XML sitemap, crawl paths, internal links, JavaScript-rendered content, mobile/HTTPS, relevant `hreflang` and measured Core Web Vitals. Robots and noindex differ; sitemap does not ensure indexing.
4. **Content:** search intent, helpful and accurate text, page titles, H1/H2, meta descriptions, clean URL structure, image alt and topic-relevant internal links. Do not recommend keyword stuffing or fake reviews, sources and mass-produced low-value pages.
5. **Structured data:** types must match actual on-page facts, validate JSON-LD against current search rules; valid markup **does not guarantee** rich results or rankings.
6. For commerce verify real products/categories/prices; for local SEO verify real contact/address; for international sites verify locales/hreflang; for migrations verify redirect map. Do not invent facts.
7. Prioritize `P0-P3` with page, observation, evidence, confidence/status, impact hypothesis, exact fix and validation. P0 = unintended critical indexing block; P1 = high-impact defect; P2 = actionable improvement; P3 = optional.
8. Finish with changes and how to measure follow-up using real Search Console/analytics if available. No unauthorized writes, merges or deploys. If new UI is involved, SEO does not override UX/UI Design Orchestra's visual approval gate.

[Checklist and primary sources](references/CHECKLIST.md). Verify official documentation freshness when possible. No commercial SEO suite or paid API needed.
